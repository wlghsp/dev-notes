# bitwise-operations (비트 연산)

비트 단위로 동작하는 연산. AND, OR, XOR, NOT 네 가지가 기본이다.

## 기본 연산

NOT (~): 비트 반전. 0→1, 1→0
AND (&): 둘 다 1일 때만 1
OR  (|): 하나라도 1이면 1
XOR (^): 다를 때 1, 같을 때 0

```
a   = 0110
b   = 1100

~a      = 1001
a & b   = 0100
a | b   = 1110
a ^ b   = 1010
```

## 비트 마스킹

특정 비트만 선택하거나 조작할 때 사용한다.

특정 비트 추출 — AND로 원하는 비트만 남긴다.
```c
x & 0xFF     // 하위 8비트만 추출
x & 0x0F     // 하위 4비트만 추출
```

특정 비트 설정 — OR로 원하는 비트를 1로 만든다.
```c
x | (1 << 3) // 3번 비트를 1로
```

특정 비트 클리어 — AND + NOT으로 원하는 비트를 0으로 만든다.
```c
x & ~(1 << 3) // 3번 비트를 0으로
```

## XOR의 특별한 성질

a ^ a = 0 (자기 자신과 XOR하면 0)
a ^ 0 = a (0과 XOR하면 자기 자신)

이 성질로 임시 변수 없이 두 값을 swap할 수 있다:
```c
x = x ^ y;
y = x ^ y;
x = x ^ y;
```

## 논리 연산과 구분

C에서 &&, ||, !는 논리 연산이고 &, |, ~은 비트 연산이다. 혼동하면 버그가 생긴다.

논리 연산은 0이 아닌 값을 true로 처리하고 결과가 0 또는 1이다. 비트 연산은 비트 단위로 처리하고 결과가 임의의 값이다.
