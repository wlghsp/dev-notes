# 토크나이제이션 (Tokenization)

텍스트를 모델이 처리할 수 있는 토큰 단위로 분리하는 과정이다.
같은 문장이라도 어떤 토크나이저를 쓰느냐에 따라 분리 결과가 달라진다.

## 왜 알고리즘이 필요한가

단순히 공백으로 쪼개면 "unhappiness"는 통째로 하나의 토큰이 된다.
처음 보는 단어(out-of-vocabulary)가 생기고, 어휘 목록이 폭발적으로 커진다.
반대로 문자 단위로 쪼개면 어휘 목록은 작아지지만 토큰 시퀀스가 너무 길어져 의미 포착이 어렵다.
그 중간을 찾는 게 토크나이제이션 알고리즘의 목표다.

## BPE (Byte Pair Encoding)

GPT 계열 모델이 쓰는 대표적인 알고리즘이다.

학습 방식은 이렇다.

1. 처음에는 모든 문자를 단위로 시작한다.
2. 전체 코퍼스에서 가장 자주 붙어 나오는 문자 쌍을 합친다.
3. 반복해서 자주 등장하는 서브워드 단위를 어휘 목록에 추가한다.
4. 어휘 목록 크기 한도에 도달하면 멈춘다.

결과적으로 자주 등장하는 단어는 통째로 하나의 토큰이 되고,
드물게 등장하는 단어는 서브워드 조각들로 쪼개진다.

## WordPiece

BERT가 쓰는 알고리즘이다.
BPE와 비슷하지만 쌍을 합칠 때 빈도가 아니라 언어 모델 확률 기준으로 선택한다.
서브워드 앞에 `##`을 붙여 단어 중간에 이어지는 조각임을 표시한다.

```
"playing" → ["play", "##ing"]
```

## 토크나이저는 모델에 고정된다

토크나이저는 모델 학습 시 함께 결정되고, 추론 시에도 동일한 토크나이저를 써야 한다.
GPT-4 토크나이저로 분리한 토큰을 BERT에 넣으면 제대로 동작하지 않는다.
