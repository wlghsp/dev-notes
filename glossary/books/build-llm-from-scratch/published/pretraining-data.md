# 사전학습 데이터

LLM 사전학습에는 수천억 개의 토큰 규모의 비레이블 텍스트 데이터가 필요하다. 이 데이터의 규모와 다양성이 LLM의 언어 이해 능력 수준을 결정한다.

## GPT-3 사전학습 데이터 구성

GPT-3는 총 약 3,000억 토큰으로 학습됐다.

- CommonCrawl (필터링) — 웹 크롤 데이터, 4,100억 토큰 중 일부 사용, 전체의 60%
- WebText2 — 웹 크롤 데이터, 190억 토큰, 22%
- Books1 — 인터넷 기반 도서 말뭉치, 120억 토큰, 8%
- Books2 — 인터넷 기반 도서 말뭉치, 550억 토큰, 8%
- Wikipedia — 고품질 텍스트, 30억 토큰, 3%

이 데이터는 총 499억 토큰이지만 실제 학습에는 300억 토큰만 사용됐다. 이유는 논문에 명시되지 않았다.

## Raw Text란

사전학습에 사용하는 텍스트를 raw text라고 부른다. 레이블 정보 없이 순수하게 텍스트만 있는 상태를 의미한다. LLM은 이 텍스트로 self-supervised learning — 다음 단어 예측을 통해 스스로 레이블을 만들어가며 학습한다.

## 스케일이 중요한 이유

데이터의 규모와 다양성은 언어 문법, 의미론, 맥락은 물론 일반 상식까지 포착하게 한다. CommonCrawl 데이터 하나만 해도 약 570GB 용량이다.

Meta의 LLaMA 같은 후속 모델들은 Arxiv 논문(92GB), StackExchange 코드 Q&A(78GB) 등 더 다양한 소스를 포함해 훈련 범위를 확장했다.

## 비용

GPT-3 사전학습 비용은 클라우드 컴퓨팅 크레딧 기준으로 약 460만 달러로 추산된다. 이 때문에 이 책에서는 소규모 교육용 데이터로 학습 구조를 구현하고, 이미 학습된 GPT-2 가중치를 로드해 사전학습 단계를 건너뛰는 방식을 함께 다룬다.
