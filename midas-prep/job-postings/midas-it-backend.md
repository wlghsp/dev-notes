# 백엔드 개발자 채용 (CDC 기술자)

마이다스는 사람 중심의 경영 철학을 바탕으로 채용·진단·육성의 새로운 패러다임을 제시하는 HR 솔루션을 통해 시장을 선도하는 기술 기업입니다. 그 중에서도 에이치닷 채용 솔루션은 연간 200만 명 이상의 지원자와 1만 명 이상의 인사담당자가 사용하는 대규모 서비스입니다.

마이다스는 기존 ATS를 넘어, AI Agent를 결합하여 채용 과정을 자동으로 수행하고 의사결정을 지원하는 방향으로 서비스를 발전시키고 있습니다. 채용 과정에서 발생하는 다양한 데이터와 이벤트를 실시간으로 처리하고, 이를 기반으로 AI가 판단하고 행동하는 환경을 구현하며 채용의 새로운 기준을 만들어가고 있습니다.

해당 포지션은 데이터 변경을 실시간으로 수집·처리하고, 이를 안정적으로 전달하는 데이터 흐름을 설계하는 백엔드 엔지니어입니다. CDC 기반 데이터 파이프라인과 고가용성 백엔드 시스템을 설계하며, 대규모 트래픽 환경에서 데이터 정합성·지연·안정성을 동시에 해결하는 데 기여할 인재를 찾고 있습니다.

## 주요 업무

- 채용 서비스 백엔드 개발
  - ATS, 역검(역량검사) 서비스의 Spring Boot 기반 서버 개발
  - 안정적이고 확장 가능한 API 및 서비스 구조 설계
- CDC 기반 데이터 파이프라인 구축
  - Debezium 기반 CDC 시스템 설계·운영 및 데이터 변경 이벤트 처리
  - Kafka 등 메시지 기반 아키텍처를 활용한 downstream 시스템 연계
- 고가용성 시스템 설계 및 개선
  - 장애 상황에서도 서비스 지속성을 보장하는 고가용성 아키텍처 설계
  - Retry, Circuit Breaker, 비동기 처리 등을 활용한 안정성 및 확장성 개선
- 데이터 플랫폼 연계 개발
  - S3 기반 데이터 레이크 및 Iceberg 테이블 기반 데이터 관리 구조 설계
  - Athena, DBT를 활용한 데이터 분석 환경 연계 개발

## 인재상

- 단순 기능 구현을 넘어, 시스템 전체의 안정성을 고민하는 엔지니어
- 데이터 흐름과 서비스 구조를 함께 이해하는 풀스택 고민형 백엔드 개발자
- 장애를 사후 대응이 아닌 구조 설계로 예방하려는 관점을 가지신 분
- 기술 선택의 이유를 명확하게 설명할 수 있는 분

## 자격 요건

- 대용량 트래픽 또는 데이터 환경에서 서비스를 개발·운영해 본 경험이 있으신 분
