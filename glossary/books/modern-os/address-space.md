# address-space

프로세스가 사용할 수 있는 메모리 주소의 집합.

OS는 각 프로세스에게 독립적인 가상 주소 공간을 제공한다. 프로세스 A의 주소 0x1000과 프로세스 B의 주소 0x1000은 서로 다른 물리 메모리 위치를 가리킨다. 이 덕분에 프로세스들은 서로를 침범하지 않고 실행될 수 있다.

일반적인 주소 공간의 구조 (아래에서 위로):
1. 코드 영역 — 실행 명령어, 읽기 전용
2. 데이터 영역 — 전역/정적 변수
3. 힙 — 동적 할당 (malloc/new), 위쪽으로 증가
4. 스택 — 함수 호출 프레임, 로컬 변수, 아래쪽으로 증가

가상 주소를 물리 주소로 변환하는 것은 MMU(Memory Management Unit)가 담당한다. OS는 페이지 테이블을 관리해 이 변환 규칙을 정의한다.

프로세스가 자신의 주소 공간 밖을 접근하려 하면 세그멘테이션 폴트가 발생하고 OS가 프로세스를 종료한다.
