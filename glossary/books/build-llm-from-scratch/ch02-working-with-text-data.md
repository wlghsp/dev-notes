이 챕터의 목적은 하나다. 텍스트를 LLM이 처리할 수 있는 숫자 벡터로 만드는 파이프라인 전체를 구현하는 것이다.

## 전체 흐름

```
원본 텍스트
  ↓ 토크나이제이션
토큰 리스트 ["This", "is", "an", "example", "."]
  ↓ 어휘사전 매핑
토큰 ID [40134, 2052, 133, 389, 12]
  ↓ 임베딩 레이어 (룩업)
토큰 임베딩 벡터 (각 토큰 → 768차원 벡터)
  ↓ 위치 임베딩 더하기
입력 임베딩 (위치 정보 포함)
  ↓
GPT 모델 입력
```

## 1단계: 토크나이제이션

텍스트를 개별 토큰으로 분리한다. 공백과 구두점을 기준으로 쪼갠다. 대소문자는 유지한다.

단순 정규식 토크나이저는 훈련 데이터에 없는 단어를 처리할 수 없다. 이 문제를 해결하는 두 가지 방법이 있다.

하나는 `<|unk|>` 특수 토큰으로 미등록 단어를 대체하는 것이다. 다른 하나는 BPE로 단어를 서브워드 단위까지 분해하는 것이다. GPT는 BPE를 선택해서 `<|unk|>`가 필요 없다.

## 2단계: 어휘사전과 토큰 ID

모든 고유 토큰을 알파벳순으로 정렬해서 정수와 1대1 매핑한다. 이 매핑이 어휘사전이다. 토큰 → ID(encode), ID → 토큰(decode) 양방향 변환이 필요하다.

GPT-2 BPE 어휘사전 크기는 50,257이다.

## 3단계: BPE

자주 등장하는 문자 쌍을 반복적으로 합쳐 서브워드 어휘를 구성한다. 흔한 단어는 하나의 토큰, 드문 단어는 여러 서브워드로 쪼개진다. 어떤 미등록 단어도 개별 문자까지 분해하면 처리할 수 있다.

## 4단계: 슬라이딩 윈도우 샘플링

다음 단어 예측 태스크를 위한 입력-타깃 쌍을 만든다. 입력 시퀀스와 타깃은 1칸 오른쪽으로 밀린 시퀀스다. `stride`로 배치 간 겹침을 조절한다.

## 5단계: 토큰 임베딩

토큰 ID를 가중치 행렬에서 룩업해 고차원 벡터로 변환한다. 이 가중치는 학습 중에 최적화된다. 같은 토큰 ID는 위치에 무관하게 항상 같은 벡터를 반환한다.

## 6단계: 위치 임베딩

토큰 임베딩은 위치 정보가 없다. 위치 인덱스 [0, 1, 2, ...]를 별도 임베딩 레이어에 통과시켜 위치 벡터를 만들고, 토큰 임베딩에 더한다. GPT는 이 위치 임베딩도 학습 파라미터로 두고 함께 학습한다.

최종 입력 임베딩 shape: `(batch_size, context_length, embedding_dim)` — 예: `(8, 4, 256)`
