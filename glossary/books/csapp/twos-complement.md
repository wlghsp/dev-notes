# twos-complement (2의 보수)

음수를 포함한 정수를 비트로 표현하는 방식. 현대 CPU 거의 전부가 이 방식을 사용한다.

## 핵심 아이디어

최상위 비트(MSB, sign bit)에 음수 가중치를 부여한다. w비트에서 MSB의 가중치는 −2^(w−1).

공식 (4비트 예시):
- [0001] = −0×8 + 0 + 0 + 1 = 1
- [0101] = −0×8 + 4 + 0 + 1 = 5
- [1011] = −1×8 + 0 + 2 + 1 = −5
- [1111] = −1×8 + 4 + 2 + 1 = −1

## 표현 범위

w비트 2의 보수 범위: −2^(w−1) ~ 2^(w−1) − 1

- 8비트: −128 ~ 127
- 16비트: −32,768 ~ 32,767
- 32비트: −2,147,483,648 ~ 2,147,483,647

범위가 비대칭이다. 음수가 양수보다 하나 더 많다. 0이 양수 쪽에 포함되기 때문이다.

## 왜 2의 보수인가

다른 표현 방식들(1의 보수, sign-magnitude)은 0을 두 가지로 표현하는 문제가 있다. 2의 보수는 0이 유일하고, 덧셈 회로를 signed/unsigned 구분 없이 동일하게 쓸 수 있어서 하드웨어 구현이 단순하다.

## 음수 만드는 법

x의 2의 보수 표현에서 −x를 구하려면: 모든 비트를 반전하고 1을 더한다.

예: 5 = [0101] → 비트 반전 [1010] → +1 → [1011] = −5

## -1의 특별한 성질

-1은 w비트에서 항상 모든 비트가 1이다. 4비트면 [1111], 8비트면 [11111111]. unsigned로 해석하면 최댓값(UMax)과 같은 비트 패턴이다.
