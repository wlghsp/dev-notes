# instruction-set

명령어 집합(instruction set)은 특정 프로세서가 이해할 수 있는 모든 기계어 명령의 목록이다. 프로세서는 바이트 값만 읽는다. 그 바이트가 어떤 연산인지를 정의한 것이 명령어 집합이다.

## opcode와 명령어

각 명령어는 opcode(연산 코드)로 시작한다. 8비트 프로세서에서는 opcode가 1바이트이므로 최대 256가지 명령이 가능하다. Intel 8080은 244개의 opcode를 갖는다.

opcode 뒤에 추가 바이트가 붙는 경우도 있다. 8080 명령어는 1바이트, 2바이트, 3바이트 중 하나다.

예시:
- `LDA A,[aaaa]` — 3바이트. opcode 1바이트 + 16비트 주소 2바이트
- `MVI E,37h` — 2바이트. opcode 1바이트 + 즉시값 1바이트
- `MOV A,B` — 1바이트. opcode만으로 완결

## 명령어의 종류 (8080 기준)

**데이터 이동**
레지스터 간, 레지스터와 메모리 간 바이트를 옮긴다.
- `MOV B,C` — 레지스터 C의 값을 B로 복사
- `LDA A,[aaaa]` — 특정 메모리 주소의 바이트를 누산기로 로드
- `MVI E,37h` — 즉시값 37h를 레지스터 E에 저장

**산술/논리 연산**
항상 누산기(A)가 한쪽 피연산자이고, 결과도 누산기에 저장된다.
- ADD, ADC (올림수 포함 덧셈), SUB, SBB (빌림수 포함 뺄셈)
- AND, OR, XOR — 비트 단위 논리 연산
- CMP — 비교. 내부적으로 뺄셈을 하고 결과는 버린다. 플래그만 남긴다.

**점프와 분기**
Program Counter를 바꿔서 실행 흐름을 제어한다.
- `JMP aaaa` — 무조건 점프
- `JZ aaaa` — Zero 플래그가 1일 때만 점프
- `JNZ aaaa` — Zero 플래그가 0일 때만 점프
- 조건: Zero, Carry, Sign, Parity 플래그 조합으로 9가지 조건부 점프

**서브루틴 (CALL / RET)**
CALL은 현재 Program Counter를 스택에 저장한 뒤 점프한다. RET는 스택에서 주소를 꺼내 Program Counter에 넣는다. 이 두 명령어가 서브루틴을 가능하게 한다. 자주 쓰는 코드를 한 번 작성하고 여러 곳에서 CALL해서 재사용할 수 있다.

**스택 조작**
- `PUSH BC` — 레지스터 쌍 BC를 스택에 저장 (2바이트)
- `POP BC` — 스택에서 2바이트를 꺼내 BC에 복원
- 스택은 RAM의 한 영역이고, Stack Pointer(SP)가 현재 위치를 가리킨다
- PUSH할 때마다 SP가 2 감소, POP할 때마다 SP가 2 증가

**입출력**
- `OUT pp` — 누산기 값을 포트 pp로 출력
- `IN pp` — 포트 pp에서 바이트를 읽어 누산기로
- 8080은 메모리 주소와 분리된 256개의 I/O 포트를 가진다

## 메모리 주소 지정 방식

명령어가 메모리에 접근하는 방법이 세 가지다.

1. 직접 주소 지정 (direct addressing) — 명령어 안에 16비트 주소가 직접 들어있다. `LDA A,[1234h]`
2. 인덱스 주소 지정 (indexed addressing) — HL 레지스터 쌍이 가리키는 주소를 쓴다. `MOV B,[HL]`
3. 즉시 주소 지정 (immediate addressing) — 주소가 아니라 값 자체가 명령어에 들어있다. `MVI A,55h`

## 플래그

산술/논리 연산 후 프로세서는 결과 상태를 플래그 레지스터(PSW)에 기록한다.
- Zero — 결과가 0이면 1
- Sign — 결과의 최상위 비트가 1이면 1 (음수)
- Carry — 올림수 또는 빌림수 발생 시 1
- Parity — 결과에서 1의 개수가 짝수면 1
- Auxiliary Carry — 하위 니블에서 상위 니블로 올림이 발생하면 1

조건부 점프 명령이 이 플래그를 읽어서 분기 여부를 결정한다. 플래그가 없으면 조건 분기가 불가능하고, 조건 분기가 없으면 반복문과 조건문을 구현할 수 없다. 플래그는 프로세서를 범용 컴퓨터로 만드는 핵심이다.
