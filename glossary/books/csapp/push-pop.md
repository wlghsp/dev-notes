# push-pop (스택 push와 pop)

스택에 데이터를 넣고 꺼내는 명령어. 함수 호출, 레지스터 보존, 반환 주소 관리에 핵심적으로 쓰인다.

## x86-64 스택 방향

스택은 높은 주소에서 낮은 주소 방향으로 자란다. `%rsp`는 항상 스택의 최상단(가장 낮은 주소)을 가리킨다.

```
높은 주소
┌──────────┐
│  이전 값  │
├──────────┤ ← 이전 %rsp
│  새 값    │
├──────────┤ ← push 후 %rsp
    ...
낮은 주소
```

## pushq S

소스 값을 스택에 push한다.

동작:
1. `%rsp -= 8`  (스택 포인터를 8 감소)
2. `M[%rsp] = S`  (새 최상단에 값 저장)

단 하나의 명령어이지만 내부적으로 두 연산이 일어난다.

## popq D

스택에서 값을 pop해서 목적지에 저장한다.

동작:
1. `D = M[%rsp]`  (최상단 값을 읽어서 저장)
2. `%rsp += 8`  (스택 포인터를 8 증가)

pop 후 메모리에 값이 남아있지만, %rsp가 위로 올라갔으므로 스택 외부가 된다. 다음 push가 그 자리를 덮어쓴다.

## call / ret과의 관계

`call` 명령어는 반환 주소를 자동으로 push하고 목적지로 점프한다.
`ret` 명령어는 반환 주소를 pop해서 그 주소로 점프한다.

내부적으로 push/pop을 사용하기 때문에 call/ret도 %rsp를 8씩 조정한다.
