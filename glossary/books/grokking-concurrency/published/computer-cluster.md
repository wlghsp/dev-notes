# Computer Cluster

각자의 CPU와 메모리를 가진 독립적인 머신들을 네트워크로 연결한 구성. 분산 메모리 시스템이다.

## SMP의 한계를 넘어서

SMP(symmetric multiprocessing)는 여러 프로세서가 공유 메모리를 함께 쓴다. 프로세서 수가 늘수록 시스템 버스가 병목이 되고, 확장에 한계가 생긴다.

이 한계를 돌파하는 방법이 공유 메모리 자체를 포기하는 것이다. 클러스터는 각 머신이 독립적으로 동작하며, 한 머신이 로컬 메모리를 변경해도 다른 머신의 메모리에 자동으로 반영되지 않는다.

## 특성

통신 비용이 크다. 머신 간 데이터 교환은 네트워크를 거쳐야 하므로, 같은 머신 내에서 프로세스 간 통신하는 것보다 훨씬 느리다.

대신 확장성이 매우 높다. 머신을 추가하는 것만으로 처리 능력을 늘릴 수 있다.

## 어떤 문제에 적합한가

- **loosely coupled** 문제 — 프로세서 간 통신이 빈번하지 않아도 되는 작업. 클러스터에 적합하다.
- **tightly coupled** 문제 — 프로세서 간 잦은 통신이 필요한 작업. 단일 머신이 유리하다.
