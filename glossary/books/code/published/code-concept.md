# code-concept (코드란 무엇인가)

정보를 전달하기 위해 약속된 기호 체계. 비밀이 아니라 소통을 위한 공통 언어다.

## 코드의 본질

코드는 송신자와 수신자가 같은 규칙을 공유할 때 동작한다. 규칙을 모르면 해독할 수 없다. 영어 단어도 코드다 — 영어를 모르는 사람에게는 그냥 기호일 뿐이다.

컴퓨터도 코드로 동작한다. 숫자, 소리, 이미지, 영상 모두 컴퓨터가 이해하는 코드로 변환되어 저장되고 전달된다.

## 코드가 필요한 이유

하나의 코드로 모든 상황을 커버할 수 없다. 말소리는 공기가 필요하고, 글자는 빛이 필요하다. 어두운 곳에서 소리 없이 원거리로 전달하려면 다른 코드가 필요하다 — 그래서 모스 부호가 등장했다.

매체(전기, 빛, 종이)가 달라지면 그 매체에 맞는 코드가 필요하다.
