# Emergent Behavior (창발적 행동)

창발(emergence)은 개별 구성 요소에는 없는 성질이 전체 시스템에서 나타나는 현상이다.

물 분자 하나에는 "축축함"이 없다. 수억 개가 모이면 액체 특성이 생긴다. 뉴런 하나는 "생각"을 못하지만, 수백억 개가 연결되면 의식이 생긴다. 이것이 창발이다.

## LLM에서의 창발

LLM은 다음 단어를 예측하는 것 하나만 학습한다. 그런데 규모가 충분히 커지면 가르치지 않은 능력이 나타난다.

- 번역 — 번역 태스크로 훈련받지 않았는데 번역이 된다
- 논리 추론 — "A이면 B, B이면 C, 그러면 A이면?" 같은 추론을 한다
- 코드 생성 — 코드를 명시적으로 학습하지 않아도 코드를 쓴다
- 수학 계산 — 산술 훈련 없이도 간단한 계산을 한다

모두 "다음 단어 예측" 하나에서 나온 결과다.

## 왜 창발이 생기는가

규모가 핵심이다. 파라미터 수가 특정 임계점을 넘으면 갑작스럽게 능력이 생긴다. 적은 파라미터로는 아무리 학습해도 나타나지 않던 능력이, 규모를 키우면 어느 순간 등장한다.

이게 왜 생기는지 아직 완전히 이해되지 않았다. 현재 AI 연구의 주요 미해결 문제 중 하나다.

## 창발이 중요한 이유

창발 이전까지는 "번역하려면 번역 모델, 요약하려면 요약 모델"이 상식이었다. 창발은 이 상식을 뒤집었다. 하나의 거대 모델이 명시적으로 훈련받지 않은 태스크를 수행하는 것이 가능해졌고, 이것이 ChatGPT 같은 범용 어시스턴트의 기반이다.
