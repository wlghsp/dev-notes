# preprocessor

컴파일 전에 소스 코드를 텍스트 수준에서 변환하는 단계.

## 핵심 아이디어

컴파일러가 코드를 보기 전에 먼저 실행된다. 코드의 의미를 해석하지 않고 텍스트를 기계적으로 치환하고 삽입한다.

## 하는 일

**헤더 파일 삽입** — `#include <stdio.h>` 를 만나면 해당 파일의 내용을 그 자리에 그대로 붙여넣는다. 컴파일러는 이미 합쳐진 하나의 소스를 본다.

**매크로 치환** — `#define MAX 100` 이 있으면 코드에서 `MAX` 가 등장하는 곳을 전부 `100` 으로 바꾼다. 함수처럼 생긴 매크로도 텍스트 치환이다.

**조건부 컴파일** — `#ifdef`, `#ifndef` 로 특정 조건일 때만 코드를 포함시킨다. 플랫폼별로 다른 코드를 하나의 파일에 관리할 때 쓴다.

## 결과

확장자 `.i` 파일. 순수한 C 소스로, `#include` 나 `#define` 같은 전처리 지시문이 전부 처리된 상태다.
