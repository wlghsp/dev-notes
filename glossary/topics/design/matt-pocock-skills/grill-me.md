# /grill-me — 만들기 전에 끝장 인터뷰

## 한 줄 요약

코드 한 줄 쓰기 전에 에이전트가 나를 인터뷰해서 내가 뭘 만들려는지 완전히 명확하게 만든다.

---

## 언제 쓰나

- 뭔가 만들려는데 머릿속에 아직 흐릿한 부분이 있을 때
- 요구사항을 적어보니 빈칸이 많을 때
- "그냥 해봐"라고 했다가 나중에 다시 만든 경험이 있을 때
- 새로운 기능, API 설계, 아키텍처 결정 앞에 섰을 때

---

## 작동 방식

에이전트가 설계 트리의 모든 분기를 하나씩 내려가며 질문한다.
질문은 한 번에 하나씩. 여러 개를 동시에 던지지 않는다.
각 질문마다 에이전트가 권장 답변을 먼저 제시한다. 내가 동의하거나 수정하면 다음으로 넘어간다.
모든 결정 분기가 해결될 때까지 계속한다.

---

## 실제 사용 예시

```
나: /grill-me 유저 인증 시스템 새로 만들려고 해

에이전트: JWT vs 세션 기반 중 어느 쪽인가요?
         권장: JWT — 서버 상태 없이 수평 확장이 쉽습니다.

나: JWT로 하자

에이전트: 리프레시 토큰 필요한가요?
         권장: 필요합니다 — 액세스 토큰 만료 시간을 짧게 유지할 수 있습니다.

나: 응
...
```

---

## /grill-with-docs와의 차이

/grill-me: 순수 인터뷰만. 간단한 결정이나 코드 없는 계획에 적합.

/grill-with-docs: 인터뷰 + 도메인 모델 구축. 진행하면서 CONTEXT.md와 ADR을 인라인으로 작성.
코드베이스가 있는 엔지니어링 작업에 더 적합.

---

## 핵심 가치

커뮤니케이션 갭은 항상 있다. 내가 머릿속에 있다고 생각한 것과 에이전트가 만드는 것 사이에.
이 갭을 코드를 짜기 전에 해결한다. 나중에 다시 만드는 것보다 10배 싸다.
