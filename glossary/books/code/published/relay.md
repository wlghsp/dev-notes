# relay (릴레이)

릴레이는 약한 입력 전류로 강한 출력 전류를 제어하는 전자기 스위치다. 사람 손이 아니라 전류가 스위치를 켜고 끈다.

## 동작 원리

입력 전류가 전자석 코일에 흐르면 자성이 생긴다. 자성이 유연한 금속 띠를 끌어당기면, 그 금속 띠가 출력 회로의 스위치를 닫는다. 입력 전류가 끊기면 자성이 사라지고 금속 띠가 원래 위치로 돌아가 출력 회로를 다시 열린 상태로 만든다.

입력 → 전자석 동작 → 금속 띠 이동 → 출력 스위치 on/off

## 장거리 전신에서의 역할

전선은 길어질수록 저항이 커지고 신호가 약해진다. 300마일이 넘으면 전류가 너무 약해져 소더를 작동시키지 못한다.

릴레이를 중간에 설치하면 약해진 신호로 릴레이를 작동시키고, 릴레이가 새 배터리에 연결된 강한 출력 회로를 켠다. 신호가 죽지 않고 이어진다.

## 릴레이로 논리 연산 만들기

릴레이는 단순한 신호 증폭 장치가 아니다. 릴레이 여러 개를 연결하는 방식에 따라 AND/OR 논리 연산이 된다.

AND — 릴레이 두 개를 직렬 연결:

```
전원 → [릴레이A] → [릴레이B] → 전구
```

A와 B 둘 다 켜져야 전류가 흐른다. 하나라도 꺼지면 회로가 끊긴다.

OR — 릴레이 두 개를 병렬 연결:

```
전원 → [릴레이A] ─┬─ 전구
       [릴레이B] ─┘
```

A 또는 B 중 하나만 켜져도 전류가 흐른다.

NOT — 릴레이 하나를 반대로:

평소에 닫혀 있다가 입력이 들어오면 열리는 릴레이를 쓰면 입력이 없을 때 전류가 흐르고, 입력이 있으면 끊긴다.

이 세 가지 조합으로 모든 논리 연산을 만들 수 있다. CPU 내부의 AND/OR/NOT 게이트가 전부 이 원리다. 지금은 릴레이 대신 트랜지스터로 구현하지만 동작 방식은 동일하다.
