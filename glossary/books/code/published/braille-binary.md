# braille-binary (점자와 이진 코드)

점자(Braille)는 6개의 점을 올리거나 내리는 방식으로 문자를 표현한다. 각 점이 이진 상태(올림/내림)를 가지므로 2⁶ = 64가지 코드가 가능하다.

## 구조

2×3 격자에 점 6개가 배치된다. 각 점은 독립적으로 올리거나 내릴 수 있다. 두 가지 상태 × 6개 자리 = 64가지 조합.

## 64가지로 무엇을 표현하는가

Louis Braille(1809~1852)이 설계한 체계:
- 소문자 26자 (알파벳)
- 숫자 (알파벳 코드를 재활용 + 숫자 표시자 prefix)
- 대문자 표시자 (다음 글자가 대문자임을 나타냄)
- 구두점 및 축약어

Grade 2 Braille에서는 자주 쓰는 단어를 단일 코드로 축약한다. "the", "and", "for" 같은 단어가 하나의 점자 셀로 표현된다.

## 이진 코드로서의 점자

점자는 64가지를 정확히 다 쓴다 — 낭비가 없다. 6비트 이진 코드와 구조가 동일하다. 매체가 전기 신호가 아니라 종이 위의 돌출된 점일 뿐이다.
