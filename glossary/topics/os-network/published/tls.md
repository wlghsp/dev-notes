# TLS (Transport Layer Security)

네트워크 통신을 암호화하는 프로토콜. 클라이언트와 서버 사이에서 데이터를 암호화해 제3자가 내용을 읽지 못하게 한다.

HTTPS는 HTTP + TLS다. 브라우저 주소창의 자물쇠 아이콘이 TLS가 적용됐다는 표시다.

## TLS가 보장하는 것

- 암호화 — 전송 중 데이터를 제3자가 읽을 수 없다
- 무결성 — 전송 중 데이터가 변조됐는지 감지할 수 있다
- 인증 — 서버가 진짜 그 서버인지 인증서로 확인한다

## SSL과의 관계

SSL은 TLS의 전신이다. SSL 3.0 이후 TLS 1.0으로 이름이 바뀌었고, 현재 SSL은 보안 취약점으로 사용이 금지됐다. "SSL"이라고 부르는 경우가 많지만 실제로는 TLS를 쓰고 있다.

## HTTP와의 관계

HTTPS = HTTP + TLS다. HTTP가 TLS를 포함하는 게 아니라, HTTP 아래에 TLS가 깔려있는 구조다.

통신 순서:
1. TCP 연결 수립
2. TLS 핸드셰이크 — 암호화 채널 수립
3. HTTP 요청/응답 — 암호화된 채널 위에서 동작

TLS는 HTTP 전용이 아니다. TCP 위에서 동작하는 프로토콜이라면 뭐든 붙일 수 있다. 이메일(SMTP), 파일 전송(FTP), DB 연결도 TLS를 적용할 수 있다.
