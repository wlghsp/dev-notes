# horizontal-scaling

**"서버를 여러 대로 늘려 부하를 분산하는 방식"**

기존 서버를 업그레이드하는 대신, 서버를 추가해서 처리 능력을 높인다. scale out이라고도 한다. 클라우드 환경에서 인스턴스를 추가하는 것이 대표적인 예다.

---

## 왜 수평 확장이 대세가 됐나

단일 프로세서의 클럭 속도 향상이 물리적 한계에 부딪히면서, 반도체 업계는 코어를 여러 개 넣는 방향으로 전환했다. 소프트웨어도 같은 흐름을 따라, 하나의 강력한 서버보다 여러 대의 서버가 협력하는 구조로 진화했다.

수평 확장은 이론적으로 자원을 계속 추가할 수 있어 확장성이 높다. 하지만 여러 머신이 함께 일하려면 동시성과 분산 처리가 전제가 된다.

---

## computing cluster

한 대의 컴퓨터로 부족할 때, 여러 대를 연결한 computing cluster가 하나의 처리 단위로 동작한다. 데이터 처리 작업을 클러스터의 여러 노드에 분산시켜 병렬로 처리한다.

---
