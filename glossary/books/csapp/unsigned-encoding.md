# unsigned-encoding (unsigned 정수 표현)

비트 벡터를 음이 아닌 정수로 해석하는 방식. 각 비트 위치 i가 2ⁱ의 가중치를 갖는다.

## 공식

w비트 벡터 [x(w-1), x(w-2), ..., x0]에 대해:

값 = x(w-1)×2^(w-1) + ... + x1×2¹ + x0×2⁰

예시 (4비트):
- [0001] = 1
- [0101] = 4 + 1 = 5
- [1011] = 8 + 2 + 1 = 11
- [1111] = 8 + 4 + 2 + 1 = 15

## 표현 범위

w비트 unsigned의 범위: 0 ~ 2ⁿ − 1

- 8비트: 0 ~ 255
- 16비트: 0 ~ 65,535
- 32비트: 0 ~ 4,294,967,295

## signed와의 차이

같은 비트 패턴이라도 signed(2의 보수)로 해석하느냐 unsigned로 해석하느냐에 따라 값이 달라진다. 예를 들어 4비트 [1111]은 unsigned로 15, signed(2의 보수)로 -1이다.

C에서 signed와 unsigned 사이에 암묵적 캐스팅이 발생할 때 비트 패턴은 그대로이고 해석 방식만 바뀐다. 이것이 C에서 unsigned 관련 버그의 주요 원인이다.
