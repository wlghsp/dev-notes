# load-balancer (로드 밸런서)

로드 밸런서는 들어오는 트래픽을 로드 밸런싱 셋에 정의된 여러 웹 서버에 고르게 분산한다.

## 동작 방식

사용자는 로드 밸런서의 Public IP로만 접근한다. 웹 서버들은 인터넷에서 직접 접근할 수 없다. 로드 밸런서와 웹 서버 사이는 Private IP로 통신한다.

Private IP는 같은 네트워크 내부 서버끼리만 통신할 수 있는 IP다. 인터넷에서는 도달할 수 없어 보안상 유리하다.

## 장애 처리

서버 1이 오프라인이 되면 로드 밸런서가 모든 트래픽을 서버 2로 보낸다. 서버 풀에 새 서버를 추가하면 로드 밸런서가 자동으로 요청을 분배하기 시작한다.

## Failover와 가용성

로드 밸런서 도입으로 웹 티어의 Failover 문제가 해결된다. 트래픽이 급증하면 서버를 추가하기만 하면 되고 로드 밸런서가 나머지를 처리한다.
