# positional-notation (위치 기수법)

숫자의 값이 그 기호 자체만이 아니라 위치에 의해 결정되는 표기법. 힌두-아라비아 수 체계의 핵심 구조다.

## 작동 방식

4825를 예로 들면:

```
4825 = 4 × 10³ + 8 × 10² + 2 × 10¹ + 5 × 10⁰
     = 4000 + 800 + 20 + 5
```

각 자리는 밑(base)의 거듭제곱을 나타낸다. 가장 오른쪽 자리가 10⁰(=1), 한 자리 올라갈수록 10의 거듭제곱이 하나씩 커진다.

## 0의 역할

위치 기수법에서 0은 자리 지킴이다. 205와 25와 250은 사용된 숫자는 같아도 0의 위치에 따라 전혀 다른 수다. 0 없이는 위치 기수법 자체가 작동하지 않는다.

## 어떤 base에도 적용된다

위치 기수법은 10진수에만 국한되지 않는다. 동일한 구조를 base 8, base 2, base 16에 모두 적용할 수 있다. 각 자리가 그 base의 거듭제곱을 나타낸다는 원칙만 유지되면 된다.

2진수 1011 = 1 × 2³ + 0 × 2² + 1 × 2¹ + 1 × 2⁰ = 8 + 0 + 2 + 1 = 11(십진수)
