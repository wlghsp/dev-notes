# BM25 (Best Match 25)

Elasticsearch의 기본 relevance score 계산 알고리즘. TF-IDF를 개선한 확률 기반 랭킹 모델이다.

"25"는 이 알고리즘 계열의 25번째 시도라는 의미다.

## TF-IDF와의 차이

TF-IDF는 단어 빈도(TF)가 높을수록 점수가 선형으로 올라간다. 같은 단어를 100번 넣으면 1번 넣은 것보다 100배 높은 점수를 받을 수 있다.

BM25는 TF에 포화(saturation) 개념을 도입했다. 단어 등장 횟수가 늘어날수록 점수 증가가 둔화된다. 단어를 반복해서 점수를 조작하는 것이 어렵다.

## 핵심 파라미터

`k1`: TF 포화 속도를 조절한다. 값이 클수록 포화가 느려져 빈도 차이가 점수에 더 많이 반영된다. 기본값 1.2.

`b`: 문서 길이 정규화 강도를 조절한다. 0이면 문서 길이를 무시하고, 1이면 완전히 정규화한다. 기본값 0.75.

## 점수 계산 요소

1. TF(term frequency): 해당 문서에서 검색 단어가 몇 번 나왔는가. BM25에서는 포화 적용.
2. IDF(inverse document frequency): 전체 문서 중 검색 단어가 포함된 문서가 얼마나 드문가. 희귀할수록 높다.
3. Field length normalization: 짧은 필드에서 단어가 나올수록 점수가 높다.

최종 점수 = IDF × (TF 포화 적용값) × (필드 길이 정규화)

## 실무에서

BM25 파라미터는 인덱스 Mapping에서 조정할 수 있다.

```json
PUT /products
{
  "settings": {
    "similarity": {
      "my_bm25": {
        "type": "BM25",
        "k1": 1.5,
        "b": 0.8
      }
    }
  }
}
```

대부분의 경우 기본값이 잘 동작한다. 도메인에 따라 짧은 문서가 많으면 `b`를 낮추는 식으로 조정한다.
