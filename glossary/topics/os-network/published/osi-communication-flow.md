# OSI 7계층 통신 흐름

클라이언트가 서버에 HTTPS 요청을 보낼 때 각 계층을 어떻게 통과하는지.

## 송신 (클라이언트 → 서버 방향)

데이터는 위에서 아래로 내려가면서 각 계층이 헤더를 붙인다.

1. 7계층 (응용) — HTTP 요청 생성. `GET /index.html HTTP/1.1`
2. 6계층 (표현) — TLS 암호화. HTTP 데이터를 암호화된 바이트로 변환
3. 5계층 (세션) — 연결 세션 관리. 실질적으로 TLS 핸드셰이크가 여기 포함
4. 4계층 (전송) — TCP 헤더 추가. 포트 번호, 순서 번호, 재전송 보장
5. 3계층 (네트워크) — IP 헤더 추가. 출발지/목적지 IP 주소
6. 2계층 (데이터링크) — MAC 주소 추가. 같은 네트워크 안에서 다음 홉으로 전달
7. 1계층 (물리) — 전기 신호 또는 광신호로 변환해서 전송

## 수신 (서버 측)

서버는 반대로 아래에서 위로 올라가면서 각 계층이 헤더를 벗긴다. 최종적으로 7계층에서 원래 HTTP 요청을 꺼낸다.

## 핵심

각 계층은 자기 아래 계층이 어떻게 동작하는지 몰라도 된다. HTTP는 TLS가 어떻게 암호화하는지 모르고, TLS는 TCP가 어떻게 재전송하는지 모른다. 각 계층은 자기 역할만 한다.
