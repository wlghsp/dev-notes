# 패킷 (Packet)

네트워크로 전송되는 데이터 단위를 부르는 말. 엄밀히는 IP 계층의 데이터 단위를 가리키지만, 실무에서는 네트워크로 오가는 데이터 덩어리를 통칭할 때도 쓴다.

## 계층마다 다른 이름

각 계층은 자기 계층의 데이터 단위를 다르게 부른다.

- 애플리케이션 계층 → 메시지 (message)
- 전송 계층 (TCP) → 세그먼트 (segment)
- 네트워크 계층 (IP) → 패킷 (packet)
- 링크 계층 (이더넷) → 프레임 (frame)

데이터가 아래 계층으로 내려가면서 헤더가 붙고 이름이 바뀐다. 참고: tcp.md

## 실무에서의 혼용

Wireshark는 캡처한 데이터를 계층 구분 없이 전부 "패킷"이라고 표시한다.
개발자들도 "패킷이 유실됐다", "패킷을 캡처했다"처럼 통칭해서 쓰는 경우가 많다.

누군가 "패킷"이라고 하면 IP 패킷을 정확히 말하는 건지, 네트워크 데이터를 통칭하는 건지 문맥으로 구분하면 된다.
