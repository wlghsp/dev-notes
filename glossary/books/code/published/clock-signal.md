# 클럭 신호 (Clock Signal)

회로 전체의 동작 박자를 맞추는 신호. 0과 1을 일정한 주기로 반복하며, 이 신호에 맞춰 플립플롭이 값을 저장하고 카운터가 증가한다.

## 왜 필요한가

여러 부품이 연결된 회로에서는 신호가 전파되는 데 시간이 걸린다. 클럭이 없으면 각 부품이 제각각 타이밍에 동작해서 잘못된 값이 저장될 수 있다. 클럭 신호는 "지금 이 순간 값을 확정해라"는 신호를 모든 부품에 동시에 보낸다.

## 오실레이터

클럭 신호를 생성하는 회로를 오실레이터(oscillator)라 한다. 실제 회로에서는 수정 진동자(quartz crystal)를 사용한다. 수정은 특정 주파수로 매우 안정적으로 진동하는 성질이 있어서 정확한 클럭 신호를 만드는 데 적합하다.

주파수는 초당 진동 횟수를 나타내며 헤르츠(Hz) 단위를 쓴다. 1MHz는 초당 100만 번. TTL 소자로 만든 Chapter 17의 컴퓨터는 10MHz 클럭에서 동작할 수 있으며, 명령어 하나를 실행하는 데 4클럭이 필요하므로 명령어 하나당 400나노초가 걸린다.

## 클럭과 명령어 실행

Chapter 17의 컴퓨터에서 명령어 하나는 3바이트로 구성된다. 메모리에서 3바이트를 순서대로 읽고 실행하는 전체 과정(명령어 사이클)에 클럭 4회가 필요하다. 클럭이 빠를수록 초당 더 많은 명령어를 실행할 수 있다.
