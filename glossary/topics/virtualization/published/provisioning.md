# 프로비저닝 (Provisioning)

프로비저닝은 필요한 자원(서버, 네트워크, 스토리지, 계정 등)을 실제로 쓸 수 있는 상태로 준비해서 내주는 것 전체를 가리킨다. "생성"은 이 과정의 일부일 뿐이다.

## 생성과 다른 점

VM을 예로 들면 프로비저닝에는 이런 단계들이 다 포함된다.

- VM 인스턴스 생성 — 디스크, 메모리, CPU 할당
- 네트워크 연결 — IP 할당, 방화벽/보안 그룹 설정
- 운영체제 설치 또는 이미지 부팅
- 접근 권한 설정 — SSH 키, 계정
- 사용 가능한 상태로 전달

즉 "만들어서 → 설정하고 → 바로 쓸 수 있게 넘겨주는" 전체 흐름을 뭉뚱그려 부르는 말이다.

## OpenStack에서 쓰이는 맥락

"OpenStack이 VM/네트워크/스토리지를 API와 코드로 프로비저닝한다"는 말은, 그냥 "만든다"가 아니라 "사용자가 요청하면 필요한 자원을 자동으로 할당하고 설정까지 마쳐서 바로 쓸 수 있게 내준다"는 뜻이다. 참고: openstack.md

이게 openstack.md에서 다룬 "셀프서비스 IaaS"라는 표현과 이어진다. 사람이 수동으로 서버실 가서 케이블 꽂고 설치하는 대신, API 호출 한 번으로 이 전체 과정이 자동으로 끝나는 것을 "프로비저닝한다"고 표현한다.

참고: openstack.md, rhosp-osp.md
