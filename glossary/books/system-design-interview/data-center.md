# data-center (데이터 센터)

서비스를 물리적으로 다른 위치의 여러 데이터센터에 분산 배치해 가용성과 글로벌 성능을 높이는 구성.

## GeoDNS 라우팅

사용자는 GeoDNS에 의해 가장 가까운 데이터센터로 라우팅된다. GeoDNS는 사용자의 위치(IP)를 기반으로 도메인을 적절한 IP 주소로 해석하는 DNS 서비스다.

예를 들어 US-East DC에 x%의 트래픽, US-West DC에 (100-x)%의 트래픽을 보낼 수 있다.

## 장애 시 트래픽 전환

DC2(US-West)가 오프라인이 되면 100% 트래픽을 DC1(US-East)으로 전환한다.

> 📷 Figure 1-16 (책 p.23) — DC2 장애 시 DC1으로 트래픽 전환 다이어그램

## 멀티 데이터센터 구성의 기술적 과제

1. 트래픽 리다이렉션 — GeoDNS로 가장 가까운 DC로 라우팅
2. 데이터 동기화 — 리전별로 다른 로컬 DB·캐시를 사용하다가 장애 시 데이터가 없을 수 있다. Netflix처럼 비동기 멀티 DC 복제로 해결한다
3. 테스트와 배포 — 자동화 배포 도구로 모든 DC에 일관되게 배포해야 한다
