# base-conversion (진수 변환)

어떤 수를 한 진수 체계에서 다른 진수 체계로 표현을 바꾸는 것. 수 자체(가리키는 양)는 변하지 않는다. 표기 방식만 바뀐다.

## 2진수 → 10진수

각 자리에 해당하는 2의 거듭제곱을 곱해 더한다.

```
1 0 0 1 0 1 1 0
↓
× 128 × 64 × 32 × 16 × 8 × 4 × 2 × 1
= 128 + 0 + 0 + 16 + 0 + 4 + 2 + 0 = 150
```

## 10진수 → 2진수

가장 큰 2의 거듭제곱부터 순서대로 나눠 몫(0 또는 1)을 기록한다.

```
150 ÷ 128 = 1 (나머지 22)
 22 ÷  64 = 0 (나머지 22)
 22 ÷  32 = 0 (나머지 22)
 22 ÷  16 = 1 (나머지  6)
  6 ÷   8 = 0 (나머지  6)
  6 ÷   4 = 1 (나머지  2)
  2 ÷   2 = 1 (나머지  0)
  0 ÷   1 = 0
→ 10010110
```

## 8진수 ↔ 2진수

2진수 3자리가 8진수 1자리에 정확히 대응된다.

```
2진수: 101 011 010
8진수:  5    3   2  → 532(octal)
```

## 16진수 ↔ 2진수

2진수 4자리가 16진수 1자리에 정확히 대응된다.

위에서 150(decimal)을 2진수로 변환한 결과가 10010110이었다. 이걸 4자리씩 끊으면 16진수로 바로 변환된다.

```
2진수: 1001 0110
16진수:  9    6  → 96(hex) = 150(decimal)
```

8진수와 16진수 변환이 단순한 이유는 8과 16이 모두 2의 거듭제곱이기 때문이다. 10진수는 2의 거듭제곱이 아니라 이런 직접 대응이 없다.
