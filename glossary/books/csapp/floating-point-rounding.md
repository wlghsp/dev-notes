# floating-point-rounding (부동소수점 반올림)

부동소수점은 표현할 수 있는 수가 이산적이다. 정확히 표현할 수 없는 값을 가장 가까운 표현 가능한 값으로 근사하는 것이 반올림이다.

## IEEE 754 반올림 모드 4가지

round-to-even (기본값, 은행가 반올림):
- 딱 중간값(halfway)이면 짝수 쪽으로 반올림
- 1.5 → 2, 2.5 → 2 (2가 짝수), 3.5 → 4
- 한 방향으로 편향되지 않아서 통계적으로 바이어스가 없다

round-toward-zero:
- 절댓값을 줄이는 방향으로 잘라낸다
- 양수는 내림, 음수는 올림

round-down:
- 항상 내림 (−∞ 방향)

round-up:
- 항상 올림 (+∞ 방향)

## round-to-even이 기본인 이유

항상 올림이나 항상 내림을 쓰면 반올림을 반복할 때 오차가 누적된다. round-to-even은 중간값에서 절반은 올리고 절반은 내리기 때문에 오차가 평균적으로 상쇄된다.

## 부동소수점 연산의 비결합성

반올림 때문에 부동소수점 덧셈은 결합법칙이 성립하지 않는다.

```c
(3.14 + 1e10) - 1e10 == 0.0       // 3.14가 반올림되어 사라짐
3.14 + (1e10 - 1e10) == 3.14      // 순서가 다르면 결과가 다름
```

컴파일러가 수식을 재배치해서 최적화하면 결과가 달라질 수 있기 때문에, 수치 계산 코드에서는 이 점을 주의해야 한다.
