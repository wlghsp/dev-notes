# resume.md 초안 (Week 1)

studypass 저장소의 resume/resume.md에 옮겨 적을 초안. 1주차는 "문장 1"만 채우면 된다 (missions/README.md Week 1 필수 항목: 수치화 패턴 문장 1개).

## 근거 범위

- 측정 대상: 이 저장소의 studypass (기본)
- 검증 가능한 범위: GET /api/studies 응답 시간(순차 요청 3회), 실행 쿼리 구조(SQL 로그)
- 확인 불가 또는 추가 측정이 필요한 범위: 동시 요청 부하 상태의 응답 시간, study 데이터가 대규모(수만 건 이상)일 때의 실측 응답 시간

## 방어 가능한 성과 문장

### 문장 1

- 문장: 동시 요청 없는 로컬 환경(MacBook Pro M3, studies 300건)에서 GET /api/studies 응답 시간을 3회 측정해 12~26ms(0.012s/0.017s/0.026s)를 확인했고, Hibernate SQL 로그 분석으로 조건절 없는 count 쿼리의 전체 스캔이 데이터 증가 시 병목이 될 것으로 예측했다.
- 본인 행동: docker compose로 MySQL 로컬 환경 구성, curl -w로 응답 시간 3회 측정(워밍업 1회 별도 처리), Hibernate SQL 로그로 실행 쿼리 구조 확인, 회귀 테스트 2건 작성
- 전후 조건과 결과: 개선 전 상태만 측정함. 성능 개선은 이후 주차(인덱스: 3주차) 대상
- 저장소 안 근거:
  - 측정 결과 및 SQL 로그: evidence/week-01__weekly-pr.md
  - 회귀 테스트: src/test/java/co/dingcodingco/studypass/study/StudyControllerTest.java
