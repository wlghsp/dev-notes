# heuristic (휴리스틱)

항상 올바른 답을 보장하지 않지만 대부분의 경우 충분히 좋은 답을 내는 절차.

알고리즘과의 차이: 알고리즘은 모든 인스턴스에서 올바른 결과를 보장한다. 휴리스틱은 보장하지 않는다. 그래서 "이 휴리스틱은 잘 동작하는 것 같다"는 말은 있어도 "이 휴리스틱은 항상 옳다"는 말은 성립하지 않는다.

TSP(Traveling Salesman Problem)에서 nearest-neighbor 휴리스틱이 대표적인 예다. 현재 위치에서 가장 가까운 미방문 점으로 이동하는 방식인데, 특정 입력에서는 최적해보다 20% 이상 나쁜 결과를 낼 수 있다.

휴리스틱이 틀렸음을 증명하는 가장 좋은 방법은 반례(counterexample)를 찾는 것이다.
