# electric-circuit (전기 회로)

전기 회로는 전류가 흐를 수 있는 닫힌 경로다. 전류는 전압(voltage)이 있고 경로가 연결되어 있을 때만 흐른다.

## 세 가지 핵심 개념

전압(voltage, V): 전류를 밀어내는 힘. 전위차. 배터리의 양극과 음극 사이에 존재한다. 단위는 볼트(V).

전류(current, I): 실제로 흐르는 전자의 양. 단위는 암페어(A).

저항(resistance, R): 전류의 흐름을 방해하는 정도. 단위는 옴(Ω).

이 세 가지는 옴의 법칙(Ohm's Law)으로 연결된다.

```
I = E / R
(전류 = 전압 / 저항)
```

## 열린 회로와 닫힌 회로

배터리 단자들이 공기로만 연결된 상태 — 저항이 극도로 높아서 전류는 거의 0이다.

배터리 양극과 음극을 전선으로 바로 연결한 상태 — 저항이 극도로 낮아서 전류가 폭발적으로 흐른다. 이를 단락(short circuit)이라 한다. 전선이 뜨겁게 달아오르거나 배터리가 소진된다. 전류가 전구 같은 부품을 건너뛰고 저항 없는 지름길로만 몰리기 때문이다.

실제 회로는 이 두 극단 사이다. 배터리와 전선 사이에 전구 같은 부품을 끼우면, 부품의 저항이 전류를 적당히 제한해서 빛을 낸다. 저항이 클수록 전류가 적게 흐르고, 작을수록 많이 흐른다.

## 전류는 반드시 돌아와야 한다

전자는 배터리 양극에서 출발해 부품을 거쳐 음극으로 돌아와야 흐를 수 있다. 양극과 음극이 전선과 부품으로 끊김 없이 이어져 있어야 한다는 뜻이다. 모양이 네모든 세모든 상관없다. 경로 어딘가가 끊기면 전자가 갈 곳이 없어서 멈춘다.
