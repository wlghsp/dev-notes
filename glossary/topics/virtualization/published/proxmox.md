# Proxmox VE

Proxmox VE(Virtual Environment)는 오스트리아 회사 Proxmox Server Solutions가 만드는 오픈소스 서버 가상화 플랫폼이다. 레드햇도 VMware도 아닌 제3의 진영이다.

## 무엇을 관리하는가

VM과 컨테이너 둘 다다. 내부적으로 KVM(하이퍼바이저 엔진)으로 VM을, LXC로 리눅스 컨테이너를 돌린다. 참고: kvm.md

관리 방식은 단일 웹 UI에서 노드 몇 대를 직접 다루는 형태다. RHV나 vCenter처럼 별도 관리 서버가 클러스터를 중앙에서 통제하는 구조와 비슷한 역할을 하지만, 설정 항목과 컴포넌트 수가 훨씬 적어서 작고 직관적인 쪽에 가깝다.

## OpenStack과 비교했을 때 왜 더 안정적으로 느껴지는가

OpenStack은 원래 대규모 멀티테넌트 클라우드(수백~수천 노드, 여러 팀이 API로 셀프서비스)를 목표로 설계됐다. Nova, Neutron, Cinder, Keystone 같은 여러 독립 서비스가 메시지 큐(RabbitMQ)와 DB를 통해 서로 통신하는 분산 시스템이라, 컴포넌트 수만큼 장애 지점도 많고 장애가 나면 어느 서비스의 어느 큐/DB 트랜잭션이 꼬였는지부터 추적해야 한다. 참고: rhosp-osp.md

Proxmox는 애초에 이 정도 규모의 멀티테넌트 IaaS를 지향하지 않는다. 노드 몇 대 규모에서 VM/컨테이너를 안정적으로 띄우고 관리하는 게 목표라서 구조가 단순하고, 그만큼 고장 날 지점도 적다.

## 그래서 어느 쪽을 써야 하나

"Proxmox는 문제없고 OpenStack은 문제 있다"는 두 제품의 결함 차이가 아니라 풀려는 문제의 규모 차이에서 온다. 여러 팀에 독립된 네트워크·쿼터를 셀프서비스로 제공해야 하는 요구사항이 실제로 있다면 그 복잡도는 Proxmox로는 감당이 안 되고, 그 정도까지 필요 없는 규모라면 Proxmox 같은 단순한 도구가 관리 부담과 장애 지점 모두 더 적다.

참고: rhosp-osp.md, rhv.md, kvm.md
