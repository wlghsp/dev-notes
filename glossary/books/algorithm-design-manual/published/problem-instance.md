# problem-instance (문제 인스턴스)

알고리즘 문제(problem)의 구체적인 입력 하나.

문제(problem)는 입력의 형태와 요구 출력을 명세한 추상적인 정의다. 인스턴스(instance)는 그 형태에 맞는 실제 구체적인 입력이다.

예를 들어 정렬 문제(sorting problem)는 "n개의 키 시퀀스를 정렬하라"는 추상적 명세다. {Mike, Bob, Sally, Jill}이나 {154, 245, 568, 324}는 각각 그 문제의 인스턴스다.

알고리즘 설계에서 중요한 구분이다. "내 알고리즘이 이 인스턴스에서 잘 동작한다"는 것이 "문제를 올바르게 푼다"는 의미가 아니다. 알고리즘의 올바름은 모든 가능한 인스턴스에서 검증해야 한다.
