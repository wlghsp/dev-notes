# Embedding (임베딩)

텍스트(단어, 문장, 문서)를 고차원 숫자 벡터로 변환한 표현이다.
숫자들의 배열이지만, 그 배열이 의미를 담고 있다는 점이 핵심이다.

의미가 비슷한 단어일수록 벡터 공간에서 가까운 위치에 놓인다.
예를 들어 "cats"와 "dogs"의 임베딩은 서로 가깝고, "cats"와 "building"은 멀다.

## Bag-of-Words와의 차이

Bag-of-Words는 단어의 빈도수를 세는 방식이라 의미를 무시한다.
"I love this movie"와 "I hate this movie"는 단어 하나만 다르지만 의미는 반대인데,
Bag-of-Words로는 이 차이를 포착하지 못한다.

임베딩은 이 문제를 해결한다. 단어가 어떤 맥락에서 어떤 단어들 옆에 등장하는지를 학습해서
의미적 관계를 수치로 인코딩한다.

## 임베딩의 종류

- **Word Embedding**: 단어 단위 벡터. word2vec이 대표적. 같은 단어는 항상 같은 벡터를 갖는다.
- **Contextualized Embedding**: 문맥에 따라 같은 단어도 다른 벡터를 갖는다. BERT 계열 모델이 생성. "bank(은행)"과 "bank(강둑)"를 다르게 표현할 수 있다.
- **Sentence/Document Embedding**: 문장이나 문서 전체를 하나의 벡터로 표현.

## 어디에 쓰이나

임베딩은 LLM 생태계 전반에서 쓰인다.

- 시맨틱 검색 — 키워드가 아닌 의미로 유사한 문서를 찾을 때
- RAG — 질문과 유사한 문서를 벡터 유사도로 검색할 때
- 텍스트 분류, 클러스터링 — 문서를 숫자 벡터로 바꿔 ML 모델에 입력할 때
