# fixed-point (고정소수점)

소수점의 위치를 미리 정해두고 정수 연산만으로 실수를 표현하는 방법이다. 소수점 자체는 저장하지 않고, 프로그램이 "소수점이 오른쪽에서 몇 번째 자리에 있다"는 것을 약속으로 안다.

## 동작 원리

예를 들어 달러와 센트를 다루는 프로그램이라면 소수점 두 자리를 고정한다. –4,325,120.25를 저장할 때는 432512025라는 정수로 저장하고, 프로그램은 항상 마지막 두 자리가 소수점 아래임을 알고 있다.

CP/M이 BCD(Binary Coded Decimal)라는 형식도 지원했다. 10진수 한 자리를 4비트로 표현한다. 0은 0000, 9는 1001. 두 자리를 1바이트에 묶으면 Packed BCD다. 금융 프로그램처럼 정확히 소수점 두 자리만 필요한 경우에 적합하다.

## 장점과 한계

장점은 단순하다. 정수 연산 그대로 쓸 수 있고, 값이 정확하다. 달러와 센트처럼 자릿수가 고정된 경우에는 부동소수점보다 안정적이다.

한계는 범위다. 지구에서 태양까지의 거리(490,000,000,000 피트)와 수소 원자 반지름(0.00000000026 피트)을 동시에 다루려면 12바이트가 필요하다. 값의 범위가 매우 넓거나 매우 작은 수가 섞이면 고정소수점으로는 감당이 안 된다.
