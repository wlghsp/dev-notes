# ascii

ASCII(American Standard Code for Information Interchange)는 문자를 숫자로 표현하기 위한 7비트 코드 표준이다. 1967년에 확정됐으며, 컴퓨터가 텍스트를 다루는 방식의 사실상 기반이 됐다.

## 왜 7비트인가

영문 대소문자 52개 + 숫자 10개 = 62개. 여기에 구두점과 공백을 더하면 64를 넘는다. 따라서 6비트로는 부족하다. 128가지를 표현할 수 있는 7비트면 충분하다. 실제로 ASCII는 95개의 출력 가능한 문자와 33개의 제어 문자로 이루어져 있다.

## 코드 구조

ASCII 코드는 세 구간으로 나뉜다.

00h~1Fh (+ 7Fh) — 제어 문자(control characters). 출력되는 문자가 아니라 동작을 지시한다. 대표적인 것들:
- 0Ah — LF (Line Feed): 다음 줄로 내려가기
- 0Dh — CR (Carriage Return): 줄 시작으로 돌아가기
- 09h — HT (Horizontal Tab): 탭
- 08h — BS (Backspace): 한 칸 뒤로
- 1Bh — ESC (Escape): 터미널 제어 시퀀스 시작

20h~7Eh — 출력 가능한 문자(graphic characters). 공백(20h)부터 시작해서:
- 20h — Space (공백)
- 30h~39h — 숫자 0~9
- 41h~5Ah — 대문자 A~Z
- 61h~7Ah — 소문자 a~z

## 중요한 패턴

대문자와 소문자는 20h 차이가 난다. 'A'는 41h이고 'a'는 61h다. 이 차이를 이용하면 코드로 대소문자 변환이 간단하다. 소문자를 대문자로 바꾸려면 20h를 빼면 된다. 비트 연산으로는 세 번째 비트(bit 5)를 0으로 만들면 된다.

숫자 문자 '0'~'9'의 코드는 30h~39h다. 이것은 이진수 값 0~9가 아니다. 텍스트 안에서 "12"는 31h 32h로 저장되는 것이지, 01h 02h나 0Ch가 아니다.

## 실제로 어떻게 쓰이나

텍스트를 저장하거나 전송할 때 각 문자를 1바이트(7비트 ASCII를 8비트로 확장해서 저장)로 표현한다. 예를 들어 "Hello, you!"는 메모리에 이렇게 들어간다:

48 65 6C 6C 6F 2C 20 79 6F 75 21

ASCII가 실용적인 이유는 알파벳 순서대로 코드가 배열되어 있다는 점이다. 문자를 정렬하거나 비교할 때 코드 숫자 대소만 비교하면 알파벳 순서가 자동으로 유지된다.
