# bit / byte (비트와 바이트)

컴퓨터가 정보를 표현하는 최소 단위.

## 비트 (bit)

0 또는 1, 두 가지 상태만 표현할 수 있는 최소 단위. 전기 신호로 보면 전압이 높으면 1, 낮으면 0이다.

컴퓨터가 비트를 쓰는 이유는 물리적으로 구현하기 쉽기 때문이다. 전기가 흐르거나 안 흐르거나, 두 상태만 구분하면 된다. 10진수처럼 10가지 상태를 하드웨어로 구분하는 건 훨씬 복잡하고 오류가 생기기 쉽다.

## 바이트 (byte)

비트 8개를 묶은 단위. 컴퓨터가 메모리를 다루는 기본 단위다.

8비트로 표현할 수 있는 값: 0 ~ 255 (2^8 = 256가지)

왜 8비트인가 — 역사적으로 문자 하나(ASCII)를 표현하는 데 7비트가 필요했고, 여유분 1비트를 더해서 8비트가 표준이 됐다. 지금은 8비트가 메모리 주소의 기본 단위로 굳어졌다.

## 단위 체계

```
1 byte  = 8 bit
1 KB    = 2^10 byte  = 1,024 byte
1 MB    = 2^20 byte  = 1,024 KB
1 GB    = 2^30 byte  = 1,024 MB
1 TB    = 2^40 byte  = 1,024 GB
```

2의 거듭제곱으로 올라간다. 10진수의 1000 단위가 아니라 2^10 = 1024 단위다. 그래서 1KB가 정확히 1000바이트가 아니라 1024바이트다.

## 16진수 (hex)

비트를 사람이 읽기 편하게 표현하는 방법. 4비트를 16진수 숫자 하나로 표현한다.

```
4비트 → 0~15 → 16진수 0~F
8비트(1바이트) → 16진수 2자리 (00 ~ FF)
```

메모리 주소를 0x1A2B 같은 형태로 쓰는 이유가 이거다. 64비트 주소를 2진수로 쓰면 64자리가 되는데, 16진수로 쓰면 16자리로 줄어든다.
