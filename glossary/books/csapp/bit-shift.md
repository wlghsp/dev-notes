# bit-shift (비트 시프트)

비트 패턴을 왼쪽 또는 오른쪽으로 이동시키는 연산.

## 왼쪽 시프트 (<<)

비트를 왼쪽으로 k칸 이동. 오른쪽은 0으로 채운다. 왼쪽에서 밀려나는 비트는 버린다.

```
[01100011] << 4 = [00110000]
```

오버플로우 없다면 ×2ᵏ 효과와 같다.

## 오른쪽 시프트 (>>)

두 종류가 있다.

논리적 오른쪽 시프트 — 왼쪽을 0으로 채운다. unsigned에 사용.
```
[10010101] >> 4 = [00001001]
```

산술적 오른쪽 시프트 — 왼쪽을 MSB(부호 비트)로 채운다. signed에 사용.
```
[10010101] >> 4 = [11111001]  // MSB가 1이므로 1로 채움
```

C는 signed 타입에 어떤 시프트를 쓸지 표준이 정하지 않는다. 실제로 거의 모든 컴파일러가 signed에는 산술, unsigned에는 논리 시프트를 쓴다.

Java는 `>>`가 산술, `>>>`가 논리로 명확하게 구분된다.

## 2의 거듭제곱 곱셈/나눗셈

왼쪽 시프트 k = ×2ᵏ
오른쪽 시프트 k = ÷2ᵏ (음수의 산술 시프트는 0 방향이 아닌 음의 무한대 방향으로 반올림)

컴파일러는 `x * 8`을 `x << 3`으로 최적화한다.

## 주의: w비트 이상 시프트

w비트 타입에서 w 이상만큼 시프트하면 C 표준상 undefined behavior다. `int x = 1; x << 32;`는 정의되지 않은 동작이다.
