# amdahl's-law

**"병렬화로 얻을 수 있는 최대 성능 향상은 직렬(sequential) 부분의 비율에 의해 제한된다"**

아무리 많은 코어를 추가해도, 반드시 순서대로 처리해야 하는 부분이 있다면 전체 성능 향상에는 상한이 생긴다.

---

## 핵심 직관

전체 작업의 10%가 sequential computation이면, 나머지 90%를 아무리 빠르게 병렬화해도 전체 속도는 최대 10배 향상에 그친다. 직렬 부분이 병목이기 때문이다.

```
속도 향상 = 1 / (S + (1 - S) / N)

S = 직렬 비율 (0~1)
N = 코어 수
```

N을 무한대로 늘리면 `(1 - S) / N → 0`이 되어 `1 / S`만 남는다. 즉 코어를 아무리 늘려도 직렬 비율이 상한을 결정한다.

```
S = 0.5 (직렬 50%) → 최대 2배
S = 0.1 (직렬 10%) → 최대 10배
S = 0.01 (직렬 1%) → 최대 100배
```

---

## 실전 의미

병렬화를 설계할 때 코어 수보다 먼저 따져야 할 것은 "직렬 구간이 얼마나 되는가"다. 직렬 구간을 줄이는 것이 코어를 늘리는 것보다 효과가 클 수 있다.

---

## Gustafson's law와의 차이

Amdahl's law는 문제 크기를 고정한 채 코어를 늘린다고 가정한다. Gustafson's law는 코어가 늘어나면 더 큰 문제를 풀 수 있다고 본다. 관점의 차이다.
