# kubernetes
참고: borg-omega.md, control-plane.md, worker-node.md, declarative-model.md

---

컨테이너화된 애플리케이션의 배포와 관리를 자동화하는 소프트웨어 시스템이다. 수십~수백 개의 서버로 구성된 클러스터 위에서 수백 개의 애플리케이션을 운영할 때 필요한 자동화를 제공한다.

이름은 그리스어로 "조타수(helmsman)"를 뜻한다. 선장(개발자/운영자)이 목적지를 정하면, 조타수(Kubernetes)가 실제로 배를 조종한다. 줄여서 k8s라고도 쓴다 — k와 s 사이에 8글자가 있어서다.

## 왜 등장했나

마이크로서비스 아키텍처가 확산되면서 배포해야 할 애플리케이션 수가 수십~수백 개로 늘었다. 각 마이크로서비스는 독립적인 배포 사이클을 갖고, 서로 다른 의존성을 가진다. 이걸 수동으로 관리하는 건 불가능하다. Kubernetes는 이 자동화 문제를 해결하기 위해 등장했다.

Google이 내부적으로 쓰던 Borg, Omega 시스템의 경험을 바탕으로 2014년 오픈소스로 공개했다. 참고: borg-omega.md

## Kubernetes가 제공하는 것

- service discovery — 다른 애플리케이션을 찾아서 통신하는 메커니즘
- horizontal scaling — 부하에 따라 인스턴스 수를 자동으로 늘리거나 줄임
- load-balancing — 여러 인스턴스에 트래픽을 분산
- self-healing — 장애가 난 애플리케이션을 자동으로 재시작하고, 노드 장애 시 다른 노드로 이동
- leader election — 여러 인스턴스 중 하나만 활성화하고 나머지는 대기 상태로 유지

## 클러스터의 OS

Kubernetes는 "클러스터를 위한 운영체제"에 비유할 수 있다. OS가 CPU/메모리를 추상화해서 프로세스에 제공하듯, Kubernetes는 서버 클러스터를 추상화해서 애플리케이션에 제공한다. 개발자는 어느 서버에 배포될지 신경 쓰지 않아도 된다.
