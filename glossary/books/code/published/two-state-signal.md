# two-state-signal (두 가지 상태 신호)

정보를 전달할 때 두 가지 상태만으로 충분하다. 모스 부호의 점/대시, 전구의 켜짐/꺼짐, 컴퓨터의 0/1이 모두 같은 원리다.

## 핵심

두 가지 상태(on/off, dot/dash, 0/1)가 여러 번 반복되면 엄청나게 많은 정보를 표현할 수 있다. 상태의 종류가 많을 필요가 없다. 반복 횟수를 늘리면 된다.

이것이 이진법(binary)의 본질이다. 컴퓨터가 두 가지 전압 상태만으로 세상의 모든 정보를 처리할 수 있는 이유다.
