# kernel-mode-user-mode

CPU가 제공하는 실행 권한 수준 구분.

현대 CPU는 최소 두 가지 실행 모드를 제공한다.

유저 모드:
- 일반 프로그램이 실행되는 모드
- 하드웨어 직접 접근 불가
- 다른 프로세스 메모리 접근 불가
- 특권 명령어(ex: I/O 포트 직접 접근) 실행 시 예외 발생

커널 모드:
- OS 커널이 실행되는 모드
- 모든 메모리와 하드웨어에 접근 가능
- 특권 명령어 실행 가능

모드 전환이 일어나는 시점:
1. 시스템 콜 — 유저 → 커널 (trap으로 진입)
2. 인터럽트 — 하드웨어 이벤트 발생 시 커널 핸들러 실행
3. 예외 — page fault, divide-by-zero 등

전환 비용이 존재한다. 레지스터 저장, 스택 전환, TLB 영향 등이 누적되면 성능에 영향을 준다. Java의 `synchronized`나 파일 I/O가 느린 이유 중 하나가 이 모드 전환에 있다.

x86-64는 Ring 0(커널)부터 Ring 3(유저)까지 4단계를 정의하지만, 대부분의 OS는 Ring 0과 Ring 3만 사용한다.
