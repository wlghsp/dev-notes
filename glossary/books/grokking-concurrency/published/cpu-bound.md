# cpu-bound

작업의 실행 속도가 CPU 성능에 의해 결정되는 작업 유형.

CPU가 쉬지 않고 연산을 수행하는 것이 병목이다. 디스크나 네트워크를 기다리는 시간이 거의 없고, 대부분의 시간을 실제 계산에 쓴다.

## 특징

CPU를 멈추게 하는 요인이 없다. I/O를 기다리거나 다른 작업의 결과를 기다리는 일 없이, CPU가 연속으로 명령을 실행한다. 작업이 빨리 끝나려면 CPU 자체가 더 빨라야 한다.

대표적인 예: 영상 인코딩, 이미지 처리, 암호화/복호화, 수치 시뮬레이션, 행렬 연산.

## 멀티코어와의 관계

CPU-bound 작업은 코어 수를 늘리면 성능이 향상된다. 여러 코어가 각각 독립적인 CPU-bound 작업을 병렬로 처리할 수 있기 때문이다. 코어 4개 = 같은 시간에 4배의 CPU 연산 가능.

반대로 단일 스레드로 CPU-bound 작업을 처리할 때는 I/O-bound 작업을 끼워 넣어도 성능 이점이 없다. CPU가 이미 100% 가동 중이기 때문이다.

## 스케줄러의 역할

스케줄러는 CPU-bound 작업과 I/O-bound 작업을 구분해서 시스템 자원을 최적으로 활용한다. CPU-bound 작업을 여러 코어에 분산하고, I/O-bound 작업이 I/O를 기다리는 동안 CPU-bound 작업이 그 자리를 차지하도록 조율한다.
