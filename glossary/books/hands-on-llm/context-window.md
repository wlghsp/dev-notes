# 컨텍스트 윈도우 (Context Window)

모델이 한 번의 추론에서 처리할 수 있는 최대 토큰 수다.
입력(프롬프트)과 출력(생성 텍스트)의 합산이 이 한도를 넘을 수 없다.

## 왜 한계가 있나

트랜스포머의 셀프 어텐션은 입력 내 모든 토큰 쌍의 관계를 계산한다.
토큰이 N개면 N×N 연산이 필요하다.
컨텍스트 윈도우가 2배가 되면 연산량은 4배가 된다.
메모리와 연산 비용 때문에 무한정 늘릴 수 없다.

## 실제 크기

모델마다 다르고 빠르게 커지고 있다.

- GPT-2: 1,024 토큰
- GPT-3.5: 4,096 토큰
- GPT-4: 128,000 토큰 (128K)
- Claude 3.5: 200,000 토큰

128K 토큰은 약 100,000 단어로, 300페이지 분량의 책 한 권에 해당한다.

## 실무에서 주의할 점

컨텍스트 윈도우를 초과하면 오래된 대화 내용이 잘려나간다.
RAG는 전체 문서를 넣는 대신 관련 청크만 검색해서 넣는 방식으로 이 한계를 우회한다.

입력이 길수록 비용도 늘어난다.
API 과금은 보통 입력 토큰 수 기준이라, 컨텍스트를 꽉 채우면 비용이 빠르게 올라간다.
