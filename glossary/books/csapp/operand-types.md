# operand-types (오퍼랜드 종류)

x86-64 명령어의 피연산자(operand)는 세 종류다. 어떤 종류냐에 따라 값을 어디서 읽고 어디에 쓰는지가 결정된다.

## 세 가지 오퍼랜드

immediate (즉값) — 명령어 안에 상수값이 직접 박혀있다.
```
$0x1F    # 31이라는 상수
$-577    # 음수도 가능
```
`$` 기호로 표시한다.

register — 레지스터의 내용을 읽거나 쓴다.
```
%rax     # rax 레지스터
%rdx     # rdx 레지스터
```

memory — 주소를 계산해서 그 주소의 메모리를 읽거나 쓴다.
```
(%rax)           # rax가 가리키는 주소의 값
4(%rax)          # rax + 4 주소의 값
(%rax,%rdx)      # rax + rdx 주소의 값
(%rax,%rdx,4)    # rax + rdx*4 주소의 값
0xFC(,%rcx,4)    # 0xFC + rcx*4 주소의 값
```

## 메모리 주소 계산 공식

가장 일반적인 형태: `Imm(rb, ri, s)`

실제 주소 = Imm + R[rb] + R[ri] × s

- Imm: 상수 오프셋 (생략 가능)
- rb: 베이스 레지스터 (생략 가능)
- ri: 인덱스 레지스터 (생략 가능)
- s: 스케일 팩터, 1/2/4/8 중 하나 (생략 시 1)

배열 접근 시 자주 쓰인다. `int a[n]`에서 `a[i]`는 `(%rax,%rdx,4)` 형태로 표현된다. rax에 배열 시작 주소, rdx에 i, 스케일 4는 int 크기.

## mov의 제약

메모리 → 메모리 이동은 단일 mov 명령어로 불가능하다. 반드시 레지스터를 거쳐야 한다.
