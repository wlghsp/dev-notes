# NLP (Natural Language Processing, 자연어 처리)

컴퓨터가 사람의 언어를 이해하고 처리하는 기술 분야다.
"자연어"란 프로그래밍 언어처럼 인위적으로 만든 게 아니라, 사람이 일상에서 쓰는 언어를 말한다.

## LLM과의 관계

NLP는 분야이고, LLM은 그 분야의 방법론 중 하나다.
NLP라는 큰 분야 안에 LLM이 있는 구조다.

LLM 이전에는 NLP 태스크마다 별도 모델을 만들었다.
번역 모델, 요약 모델, 감성 분석 모델이 각각 따로 존재했다.
LLM이 이 태스크들을 하나의 모델로 처리할 수 있게 된 게 혁신이었다.

## NLP가 다루는 주요 태스크

1. 번역 — 한국어를 영어로 변환
2. 요약 — 긴 문서를 짧게 압축
3. 감성 분석 — 텍스트가 긍정인지 부정인지 판단
4. 질문 답변 — 챗봇
5. 텍스트 분류 — 스팸 메일 필터링 등
