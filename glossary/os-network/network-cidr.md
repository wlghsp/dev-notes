# 네트워크 대역 / CIDR

IP 주소 하나가 아니라 IP 주소 범위를 표현하는 방법이다.

```
192.168.1.0/24
```

뒤의 `/24`가 핵심이다. "앞 24비트는 고정, 나머지 8비트는 자유"라는 뜻이다. IP 주소는 32비트이므로 남은 8비트로 2^8 = 256개의 주소를 표현한다.

## 숫자가 작을수록 범위가 넓다

```
192.168.1.0/32  → 192.168.1.0 딱 1개
192.168.1.0/24  → 192.168.1.0 ~ 192.168.1.255     (256개)
192.168.0.0/16  → 192.168.0.0 ~ 192.168.255.255   (65,536개)
10.0.0.0/8      → 10.0.0.0   ~ 10.255.255.255     (16,777,216개)
```

/32는 특정 IP 하나를 지칭할 때, /0은 모든 IP(0.0.0.0/0)를 뜻한다.

## 사설 IP 대역

인터넷에서 라우팅되지 않는 내부 전용 대역이다. 회사 내부망, 집 공유기, 클라우드 VPC 등에서 쓴다.

```
10.0.0.0/8         → 10.x.x.x
172.16.0.0/12      → 172.16.x.x ~ 172.31.x.x
192.168.0.0/16     → 192.168.x.x
```

집 공유기에서 기기들이 `192.168.0.x` 주소를 받는 게 이 대역이다. 외부 인터넷에서 이 주소로 직접 접근할 수 없다.

## 왜 필요한가

라우터가 패킷을 어디로 보낼지 결정할 때 IP 하나하나가 아니라 대역 단위로 판단한다.

```
목적지 10.0.1.50 → 10.0.0.0/16 대역이면 이쪽 네트워크로
목적지 그 외     → 인터넷 게이트웨이로
```

라우팅 테이블이 이 규칙들의 목록이다.

## 실제로 보이는 곳

AWS VPC 생성 시 `10.0.0.0/16` 같은 CIDR을 지정한다. 이 VPC 안에서 쓸 수 있는 IP 범위를 선언하는 것이다. 서브넷을 나눌 때 `10.0.1.0/24`, `10.0.2.0/24` 처럼 더 작은 대역으로 쪼갠다.

보안 그룹이나 방화벽 규칙에서 `0.0.0.0/0`은 "모든 IP 허용"을 뜻한다.
