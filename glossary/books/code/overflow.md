# overflow (오버플로우)

연산 결과가 해당 비트 수로 표현할 수 있는 범위를 벗어났을 때 발생하는 현상.

## 8비트 덧셈에서의 오버플로우

8비트로 표현할 수 있는 양수의 최댓값은 255(11111111)다. 두 수를 더한 결과가 255를 초과하면 9번째 비트에 올림수(Carry Out)가 발생한다. 이 9번째 비트가 오버플로우 신호다.

8비트 덧셈기에서 Carry Out이 1로 켜지면 결과가 255를 넘었다는 뜻이다.

## 언더플로우

뺄셈에서 결과가 음수가 되는 경우다. 예를 들어 8비트에서 176 - 253을 계산하면 결과가 음수가 된다. 2의 보수 방식으로 계산할 때, 빼는 수가 빼이는 수보다 크면 덧셈기의 Carry Out이 0이 된다. 이것이 언더플로우 신호다.

## 회로에서의 처리

책의 덧셈/뺄셈 기계에서는 9번째 전구가 "Overflow/Underflow" 램프다. SUB 신호와 Carry Out을 XOR 게이트에 연결해서 이 램프를 제어한다.

- 덧셈(SUB=0)일 때 Carry Out이 1이면 오버플로우다.
- 뺄셈(SUB=1)일 때 Carry Out이 0이면 언더플로우다.
