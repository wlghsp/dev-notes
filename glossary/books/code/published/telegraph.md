# telegraph (전신기)

전신기는 전기 신호를 이용해 먼 거리에서 메시지를 전달하는 장치다. Samuel Morse가 1836년 특허를 신청했고, 1844년 워싱턴-볼티모어 구간 공개 시연에 성공했다.

## 구조

전신 키(telegraph key): 송신 측의 스위치. 누르면 닫히고 놓으면 열린다. 짧게 누르면 dot, 길게 누르면 dash.

사운더(sounder): 수신 측의 전자석 장치. 키를 누르면 전자석이 금속 막대를 끌어당겨 "click" 소리가 나고, 놓으면 막대가 튀어 올라 "clack" 소리가 난다. 빠른 click-clack은 dot, 느린 click…clack은 dash.

전자석(electromagnet): 전류가 흐르면 자성을 띠고, 전류가 끊기면 자성을 잃는 코일. 전신기의 핵심 동작 원리.

## 왜 중요한가

전신기 이전까지는 즉각 통신과 장거리 통신을 동시에 할 수 없었다. 목소리는 즉각적이지만 멀리 가지 못했고, 편지는 멀리 가지만 느렸다. 전신기가 처음으로 이 두 가지를 동시에 해결했다.
