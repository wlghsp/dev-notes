# /handoff — 대화 맥락 이어받기 문서

## 한 줄 요약

현재 대화를 다른 에이전트(또는 새 세션)가 바로 이어받을 수 있는 핸드오프 문서로 압축한다.

---

## 언제 쓰나

- 대화가 길어져서 새 세션으로 이어가야 할 때
- 다른 에이전트에게 현재 작업을 넘길 때
- 복잡한 작업을 중간에 멈추고 나중에 돌아올 때
- 동료에게 현재 진행 상황을 설명해야 할 때

---

## 문서에 포함되는 것

현재 대화 내용 요약:
- 무엇을 하려고 했는지
- 무엇을 완료했는지
- 무엇이 남아있는지
- 어떤 결정을 내렸고 왜인지

"suggested skills" 섹션:
- 다음 에이전트가 써야 할 스킬 제안

이미 다른 아티팩트에 있는 내용은 중복해서 쓰지 않는다:
PRD, 계획, ADR, 이슈, 커밋, diff는 경로나 URL로 참조만 한다.

민감 정보는 제거한다:
API 키, 패스워드, 개인식별정보.

---

## 저장 위치

OS 임시 디렉토리에 저장한다. 현재 워크스페이스에는 넣지 않는다.

---

## 활용 패턴

긴 작업을 쪼갤 때:
```
나: /handoff 다음 세션에서는 결제 모듈 구현할 거야
에이전트: [핸드오프 문서 생성]
         다음 세션에서 이 파일을 붙여넣으면 바로 이어서 진행할 수 있습니다.
         suggested skills: /grill-with-docs (결제 흐름 확인), /tdd (구현)
```

새 에이전트에게 넘길 때:
```
새 세션: [핸드오프 문서 내용]
에이전트: 이전 세션에서 주문 생성 API까지 완료했군요.
         이어서 결제 연동을 진행할게요.
```
