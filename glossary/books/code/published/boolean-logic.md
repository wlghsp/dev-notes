# boolean-logic (불 논리)

조지 불(George Boole)이 1854년 만든 대수 체계. 참/거짓(1/0)만 다루며 AND, OR, NOT 세 연산으로 모든 논리를 표현할 수 있다.

## 세 가지 기본 연산

AND — 둘 다 참일 때만 참
```
0 AND 0 = 0
0 AND 1 = 0
1 AND 0 = 0
1 AND 1 = 1
```

OR — 하나라도 참이면 참
```
0 OR 0 = 0
0 OR 1 = 1
1 OR 0 = 1
1 OR 1 = 1
```

NOT — 반전
```
NOT 0 = 1
NOT 1 = 0
```

## 스위치와의 연결

10장에서 핵심 발견: 스위치 두 개를 직렬로 연결하면 AND, 병렬로 연결하면 OR가 된다.

직렬(AND) — 두 스위치가 모두 닫혀야 전류가 흐른다.
병렬(OR) — 어느 하나만 닫혀도 전류가 흐른다.

불 대수가 전기 회로로 직접 구현될 수 있다는 사실을 1938년 클로드 섀넌이 MIT 석사 논문에서 증명했다. 이것이 디지털 컴퓨터 설계의 이론적 토대가 됐다.

## 0과 1의 의미

불 논리에서 1은 "전체 집합(universe)", 0은 "공집합(empty class)"이다. 일반 대수와 달리 1+1=1이 성립한다. 모든 고양이 집합과 암고양이 집합의 합집합은 여전히 모든 고양이 집합이기 때문이다.
