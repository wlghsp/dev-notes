# 토큰 (Token)

NLP에서 텍스트를 처리하는 최소 단위다.
단어와 비슷하지만 정확히 같지는 않다.

## 단어와의 차이

토큰은 단어보다 작을 수도 있고, 클 수도 있다.
LLM은 텍스트를 단어 단위가 아니라 자주 등장하는 패턴 단위로 쪼갠다.

```
"unhappiness" → ["un", "happiness"]  (2개 토큰)
"cat"         → ["cat"]              (1개 토큰)
"나는"         → ["나", "는"]          (2개 토큰, 모델에 따라 다름)
```

영어는 평균적으로 단어 하나가 약 1.3개 토큰이다.
한국어는 조사·어미가 붙는 구조라 영어보다 토큰 수가 많아지는 경향이 있다.

## 왜 단어 단위로 안 쪼개나

단어 단위로 쪼개면 어휘 목록이 너무 커진다.
"run", "runs", "running", "runner"를 각각 다른 단어로 보면 모델이 학습해야 할 항목이 폭발적으로 늘어난다.
공통 패턴("run")을 하나의 토큰으로 공유하면 어휘 목록을 줄이면서도 의미 관계를 포착할 수 있다.

## LLM에서의 역할

LLM은 텍스트를 입력받으면 먼저 토큰으로 분리(토크나이징)한다.
각 토큰을 벡터로 변환한 뒤, 다음 토큰을 예측하는 방식으로 텍스트를 생성한다.
"토큰 수"가 LLM 비용과 속도에 직접 영향을 주는 이유가 여기에 있다.
