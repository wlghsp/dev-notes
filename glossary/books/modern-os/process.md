# process

실행 중인 프로그램의 추상화.

프로그램은 디스크에 있는 정적인 명령어 집합이다. 프로세스는 그 프로그램이 실행되는 동안의 동적인 상태 전체를 가리킨다. 같은 프로그램을 두 번 실행하면 프로세스가 두 개 생긴다.

프로세스가 갖는 것:
1. 주소 공간 — 코드, 데이터, 스택, 힙
2. 레지스터 상태 — 프로그램 카운터(PC), 스택 포인터 등
3. 열린 파일 목록
4. 실행 상태 — running / ready / blocked

OS는 프로세스를 PCB(Process Control Block)라는 자료구조로 관리한다. 컨텍스트 스위치가 일어날 때 PCB에 현재 레지스터 상태를 저장하고, 다음 프로세스의 PCB에서 복원한다.

프로세스는 최소 하나의 스레드를 가진다. 스레드는 프로세스의 주소 공간 안에서 독립적으로 실행되는 흐름이다.
