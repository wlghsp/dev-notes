# bit (비트)

정보의 최소 단위. 0 또는 1, 두 가지 상태만 표현한다. binary digit의 줄임말로, 1948년 클로드 섀넌이 처음 이 단어를 사용했다.

## 비트가 표현하는 것

비트 자체는 물리적 의미가 없다. 어떻게 해석하느냐에 따라 달라진다.

- 스위치: 열림(0) / 닫힘(1)
- 전압: 낮음(0) / 높음(1)
- 전구: 꺼짐(0) / 켜짐(1)
- 논리값: 거짓(0) / 참(1)
- 엄지: 아래(0) / 위(1)

매체는 달라도 두 상태를 구분할 수 있으면 비트를 표현할 수 있다.

## 비트가 중요한 이유

물리적으로 구현하기 가장 쉬운 상태 수가 2다. 전기가 흐르거나 안 흐르거나, 두 가지만 구분하면 된다. 10진수처럼 10가지 상태를 하드웨어로 안정적으로 구분하는 건 훨씬 어렵고 오류가 생기기 쉽다.

## 비트와 정보량

비트 수가 늘어날수록 표현할 수 있는 경우의 수가 2배씩 늘어난다. n비트면 2ⁿ가지를 표현할 수 있다. 이것이 컴퓨터가 비트를 묶어서 쓰는 이유다.
