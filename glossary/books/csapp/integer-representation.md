# integer representation (정수 표현)

컴퓨터가 정수를 비트로 표현하는 방식. 부호 없는 정수와 부호 있는 정수(2의 보수) 두 가지가 있다.

## 부호 없는 정수 (unsigned)

모든 비트를 값으로 쓴다. 음수를 표현할 수 없다.

8비트 기준:
```
00000000 = 0
00000001 = 1
11111111 = 255
```

범위: 0 ~ 2^N - 1 (N은 비트 수)

## 부호 있는 정수 — 2의 보수 (two's complement)

음수를 표현하기 위해 2의 보수 방식을 쓴다. 최상위 비트(MSB)가 부호 비트다. 0이면 양수, 1이면 음수.

8비트 기준:
```
00000000 = 0
00000001 = 1
01111111 = 127   (양수 최대)
10000000 = -128  (음수 최소)
11111111 = -1
```

범위: -2^(N-1) ~ 2^(N-1) - 1

## 왜 2의 보수인가

음수를 표현하는 방법은 여러 가지가 있었다. 단순히 최상위 비트를 부호 비트로 쓰는 방법(부호-크기 표현)도 있었는데, 이 방식은 +0과 -0이 따로 존재하고 덧셈 회로를 따로 만들어야 했다.

2의 보수는 덧셈 회로 하나로 덧셈과 뺄셈을 모두 처리할 수 있다. ALU 설계가 단순해진다.

```
5 + (-3) = 5 + (2의 보수로 표현한 -3)
         = 00000101 + 11111101
         = 100000010
         = 00000010 (올림수 버림)
         = 2  ← 맞다
```

## 2의 보수 구하는 법

양수 → 음수로 변환할 때:
1. 비트를 전부 뒤집는다 (0→1, 1→0)
2. 1을 더한다

```
3  = 00000011
뒤집기 → 11111100
+1     → 11111101  = -3
```
