# 스프링 프로그래밍 배우기 — 학습 로드맵

원본: `assets/learn-spring-programming.pdf` (springrunner.dev, 총 329페이지)

이 로드맵은 원본 PDF의 목차를 기준으로 학습 진행 상태를 추적한다.
장 단위로 순차 진행하며, 완료된 장은 실제 생성된 문서 파일을 기록한다.
지호님이 각 장의 내용으로 블로그를 쓰면서 학습하는 방식으로 진행한다.

이 시리즈의 glossary 키워드 파일은 spring/glossary/ 에 모아둔다.
(레포 전역 규칙은 glossary/topics/주제명/ 이지만, 지호님 요청으로 이 시리즈는 spring 폴더 하위에 직접 둔다.)
