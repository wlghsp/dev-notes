# memory-mapping

파일을 디스크에서 읽는 대신 가상 주소 공간에 직접 매핑해서 메모리처럼 접근하는 기법.

## 핵심 아이디어

일반적인 파일 읽기는 두 번 복사가 일어난다.

```
파일 열기 → read() 시스템 콜 → 커널이 디스크에서 읽어서 버퍼에 복사 → 유저 공간으로 복사
```

memory-mapping을 쓰면 복사 없이 파일 내용을 메모리처럼 바로 접근한다.

```
mmap() 시스템 콜 → 파일을 가상 주소 공간에 매핑
    ↓
그 주소에 접근 → page fault 발생
    ↓
OS가 디스크에서 해당 페이지를 RAM으로 올림
    ↓
이후 같은 페이지 접근은 그냥 메모리 읽기
```

## 어디에 쓰이는가

**실행 파일 로딩** — OS가 프로그램을 실행할 때 ELF/Mach-O 파일을 mmap으로 매핑한다. 전체를 RAM에 올리지 않고 접근할 때마다 page fault로 필요한 부분만 올린다.

**대용량 파일 처리** — 수 GB 파일을 전부 read()로 읽지 않고 mmap으로 매핑해서 필요한 부분만 접근한다.

**프로세스 간 공유 메모리** — 같은 파일을 두 프로세스가 mmap하면 같은 물리 페이지를 공유한다. 별도의 복사 없이 프로세스 간 데이터를 공유할 수 있다.
