# Self-Attention

문장 내 토큰들이 서로 얼마나 관련 있는지 계산하는 메커니즘이다.
트랜스포머의 핵심 아이디어이며, RNN/LSTM과 가장 크게 구분되는 부분이다.

## 왜 필요한가

다음 토큰을 예측할 때 이전 토큰들이 모두 동등하게 중요하지 않다.
"나는 사과를 좋아한다"에서 "좋아한다"를 예측할 때, "사과를"이 "나는"보다 더 관련 있다.
Self-Attention은 이 관련도를 숫자로 계산해서 가중치를 부여한다.

```
"좋아한다" 예측 시:
  "나는"      → 가중치 0.1
  "사과를"    → 가중치 0.7
  "좋아한다"  → 가중치 0.2  (자기 자신도 참조)
```

## "Self"가 붙은 이유

외부 입력이 아니라 문장 자기 자신 내부의 토큰들끼리 서로를 참조하기 때문이다.
인코더+디코더 구조에서 인코더 출력을 참조하는 건 Cross-Attention이라고 따로 부른다.

## RNN과의 차이

RNN은 이전 토큰을 순서대로 하나씩 읽으면서 hidden state에 누적한다.
Self-Attention은 이전 토큰 전체를 한 번에 참조하고, 각각의 관련도를 직접 계산한다.
순서대로 처리할 필요가 없으니 병렬화가 가능하고, 멀리 떨어진 토큰도 직접 참조할 수 있다.
