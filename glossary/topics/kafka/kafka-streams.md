# Kafka Streams

**한 줄 정의**: Kafka 안에 내장된 스트림 처리 라이브러리. 별도 클러스터 없이 앱 안에서 돌아간다.

---

## 무엇인가

Kafka Streams는 Kafka 토픽에서 데이터를 읽어서 가공하고, 결과를 다시 Kafka 토픽에 쓰는 파이프라인을 만드는 Java 라이브러리다.

```
Kafka 토픽 (입력)
     ↓
Kafka Streams 앱 (필터 / 변환 / 집계)
     ↓
Kafka 토픽 (출력)
```

Flink나 Spark 같은 별도 클러스터가 필요 없다. 일반 Java 앱에 라이브러리로 추가해서 쓴다.

---

## 특징

Kafka에 붙어서 동작하기 때문에 Kafka 없이는 쓸 수 없다. Kafka가 전제조건이다.

처리 로직은 Java 코드로 작성한다. 토픽에서 읽고, 필터하고, 변환하고, 집계하는 과정을 메서드 체이닝으로 표현한다.

상태 관리를 내장하고 있다. "이 사용자가 오늘 몇 번 이벤트를 발생시켰는가" 같은 집계를 로컬 상태 저장소(RocksDB)에 들고 있다가 처리한다.

---

## 언제 쓰는가

단순한 변환이나 필터링, Kafka 토픽 간 데이터 가공이 필요할 때 적합하다. Kafka 인프라만 있으면 되고, 추가 클러스터를 운영할 필요가 없어서 도입 비용이 낮다.

처리 규모가 크거나 복잡한 조인, 대규모 윈도우 집계가 필요하면 Flink가 더 적합하다.
