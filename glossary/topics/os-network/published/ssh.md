# SSH (Secure Shell)

원격 서버에 안전하게 접속하기 위한 프로토콜. 터미널 명령어를 암호화된 채널로 주고받는다.

`ssh user@192.168.1.1` 하면 원격 서버의 쉘을 내 터미널에서 쓸 수 있다.

## TLS와의 차이

둘 다 암호화 통신이지만 목적이 다르다.

- TLS — 데이터 전송 암호화. HTTP, SMTP 등 위에 얹어서 씀
- SSH — 원격 쉘 접속 자체가 목적. 자체 암호화 포함

TLS는 프로토콜 아래에 깔리는 계층이고, SSH는 그 자체가 완결된 프로토콜이다.

## 인증 방식

- 비밀번호 인증 — 접속 시 패스워드 입력
- 키 인증 — 공개키/개인키 쌍 사용. 서버에 공개키를 등록해두고, 클라이언트는 개인키로 인증. 비밀번호보다 안전하고 자동화에 적합

## SSH가 쓰이는 곳

- 서버 원격 접속
- 파일 전송 (scp, sftp)
- 포트 포워딩 — 원격 서버의 포트를 로컬로 터널링
- Git 원격 저장소 접속 (`git clone git@github.com:...`)
