# page-fault

프로세스가 가상 주소에 접근했을 때 해당 페이지가 RAM에 없으면 발생하는 이벤트.

## 핵심 아이디어

에러가 아니다. "이 페이지가 RAM에 없으니 OS야 네가 가져와"라는 신호다. OS가 개입해서 디스크에서 해당 페이지를 RAM으로 올리고, 프로세스는 그 동안 대기했다가 정상적으로 접근을 이어간다.

```
프로세스가 가상 주소에 접근
    ↓
MMU가 페이지 테이블 확인
    ↓
해당 페이지가 RAM에 없음 (디스크/swap에 있음)
    ↓
page fault 발생 → OS가 개입
    ↓
OS가 디스크에서 해당 페이지를 RAM으로 올림
    ↓
프로세스가 정상적으로 접근 계속
```

## 왜 느린가

메모리 접근 한 번에 디스크 I/O가 끼어든다. RAM 접근은 나노초 단위지만 디스크 접근은 밀리초 단위다. swap이 자주 발생하는 서버가 느려지는 근본 이유가 여기 있다.
