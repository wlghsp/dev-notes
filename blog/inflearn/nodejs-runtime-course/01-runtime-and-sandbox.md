# [강의 노트] 1강: Node.js의 본질과 운영체제 기반의 런타임 환경 이해

## 1. 개요 및 배경 (Overview & Background)

본 강의는 자바스크립트(JavaScript)가 웹 브라우저라는 제한된 환경을 넘어, 서버 사이드 및 시스템 레벨에서 어떻게 동작하게 되었는지 그 근본적인 원리를 탐구합니다. 단순히 API 코드를 따라 치는 것을 넘어, Node.js의 아키텍처가 시스템 자원을 다루는 방식을 이해함으로써 안정적이고 고효율의 백엔드 시스템을 설계하는 시니어 엔지니어의 시각을 기르는 데 목적이 있습니다.

## 2. 핵심 내용 및 흐름 (Core Concepts & Workflow)

### 2.1 Node.js의 정의: 언어가 아닌 '런타임'

Node.js를 Python, Java 같은 새로운 언어나 React 같은 프레임워크로 오해하는 경우가 많습니다. 하지만 Node.js는 자바스크립트 코드를 컴퓨터 운영체제(OS) 위에서 직접 실행할 수 있게 해주는 **런타임 환경(Runtime Environment)**입니다.

자바스크립트라는 코드가 연극의 '대본'이라면, 런타임 환경은 그 대본이 연기되는 '무대 세트장'입니다. 과거에는 웹 브라우저라는 한정된 실내 세트장에서만 실행될 수 있었으나, Node.js라는 새로운 무대가 등장하면서 동일한 자바스크립트 대본으로 하드웨어와 서버라는 훨씬 넓은 영역을 통제할 수 있게 되었습니다.

### 2.2 기술적 혁신: 한계를 부순 V8 엔진과 C++의 결합

본래 자바스크립트는 운영체제의 메모리에 접근하거나 하드디스크의 파일을 제어하는 등의 무거운 시스템 레벨 작업이 원천적으로 불가능했습니다. 이는 브라우저 환경의 강력한 보안 정책 때문이었습니다.

Node.js는 이 한계를 기발한 아키텍처로 극복했습니다. 구글 크롬 브라우저의 핵심인 고성능 자바스크립트 해석기(V8 엔진)를 떼어내어, 그 겉을 컴퓨터 운영체제와 직접 소통할 수 있는 C++ 프로그램으로 감싸버린 것입니다. 즉, 브라우저에 갇혀있던 자바스크립트에게 C++라는 강력한 시스템 제어용 '수트'를 입혀, 파일 시스템 조작이나 네트워크 포트 개방과 같은 마법 같은 권한을 부여했습니다.

### 2.3 실무적 관점: I/O 집약적 vs CPU 집약적

"Node.js가 모든 백엔드를 완벽하게 처리하는 만능 도구인가?"라는 질문에 대한 답은 "아니오"입니다. 서비스의 성격에 따라 기술 도입의 성패가 갈립니다.

- **I/O 집약적 서비스 (I/O Bound)**: 데이터의 입력과 출력(Input/Output)이 매우 빈번하게 일어나는 서비스입니다. 카카오톡이나 디스코드 같은 실시간 채팅, 넷플릭스 같은 스트리밍, 끊임없이 데이터베이스를 읽고 쓰는 작업이 여기에 속합니다. Node.js는 이러한 요청을 대기 상태 없이 비동기적으로 아주 가볍고 빠르게 넘기며 처리하는 데 타의 추종을 불허하는 성능을 냅니다.
- **CPU 집약적 서비스 (CPU Bound)**: 컴퓨터의 두뇌인 CPU가 복잡한 수학적 연산을 오랫동안 수행해야 하는 작업입니다. 4K 고화질 비디오 영상 압축, 수백만 건의 금융 데이터 통계 계산, 인공지능 모델 학습 등이 포함됩니다. Node.js는 한 번에 하나의 작업만 꽉 쥐고 처리하는 특성이 있어, 무거운 계산 하나를 처리하는 동안 다른 사용자의 로그인이나 클릭 요청이 모두 멈춰버리는(Blocking) 치명적인 문제를 야기할 수 있으므로 도입에 매우 신중해야 합니다.

## 3. 코드 구조와 환경에 따른 권한의 변화

프론트엔드와 백엔드에서 똑같은 문법의 자바스크립트 코드를 작성하더라도, 그것이 실행되는 '환경'에 따라 할 수 있는 일의 범위가 완전히 달라집니다.

```javascript
// 프론트엔드와 백엔드에서 동일하게 동작하는 자바스크립트 함수
function sayHello(name) {
  console.log(`안녕하세요, ${name}님!`);
}

sayHello('mike');

/*
 [실행 환경에 따른 맥락 이해]
 1. 이 코드를 '웹 브라우저'에서 실행할 경우:
    - 운영체제의 파일 시스템이나 네트워크 포트에 직접 접근할 수 없습니다.
    - 브라우저가 허락한 화면 UI 조작, 애니메이션 처리 등에만 활용됩니다.

 2. 이 코드를 'Node.js' 환경에서 실행할 경우:
    - 개발자는 자바스크립트 문법 그대로 운영체제의 권한을 빌려올 수 있습니다.
    - fs(File System) 모듈을 불러와 하드디스크에 파일을 저장하거나,
    - http 모듈을 사용해 전 세계 수만 명의 접속을 받는 웹 서버 포트를 직접 열 수 있습니다.
*/
```
