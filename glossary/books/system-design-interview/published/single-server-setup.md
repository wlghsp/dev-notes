# single-server-setup (단일 서버 구성)

모든 것이 하나의 서버에서 돌아가는 가장 단순한 시작점. 웹 앱, DB, 캐시가 전부 한 서버에 있다.

## 요청 흐름

1. 사용자가 도메인명(api.mysite.com)으로 접근한다
2. DNS가 도메인을 IP 주소로 변환해서 반환한다 — DNS는 3rd party 유료 서비스
3. 브라우저 또는 모바일 앱이 IP로 직접 HTTP 요청을 보낸다
4. 웹 서버가 HTML 페이지 또는 JSON 응답을 반환한다

## 트래픽 소스

웹 서버로 들어오는 트래픽은 두 종류다.

1. 웹 애플리케이션 — 서버 사이드(Java, Python 등)로 비즈니스 로직을, 클라이언트 사이드(HTML, JS)로 렌더링을 처리
2. 모바일 애플리케이션 — HTTP 프로토콜로 통신, 응답은 주로 JSON 포맷

## 한계

단일 서버는 사용자 수가 늘어나면 한계에 부딪힌다. 웹 트래픽과 DB를 독립적으로 확장하려면 서버를 분리해야 한다. 이 분리가 수평 확장의 첫 단계다.
