# code-reuse (코드 재활용)

같은 코드 값을 문맥에 따라 다르게 해석하는 방식이다. 64가지라는 제한된 공간 안에서 더 많은 것을 표현하기 위해 쓴다.

## 점자에서의 재활용

점자는 6비트 64가지가 전부다. 알파벳 26자, 구두점, 숫자까지 모두 담으려면 64가지로는 부족하다.

Louis Braille의 해결책은 접두 코드(prefix code)였다.

숫자 표시자(number indicator): 이 코드가 나오면 다음에 오는 점자 셀들을 숫자로 해석하라는 신호다. a~j를 1~0으로 재활용한다. 숫자 표시자 없이 같은 셀이 오면 알파벳이고, 숫자 표시자 뒤에 오면 숫자다.

대문자 표시자(capital indicator): 이 코드가 나오면 바로 다음 한 글자를 대문자로 해석하라는 신호다. 소문자 코드를 그대로 재활용하되 의미만 바뀐다.

## 핵심 구조

재활용이 가능한 이유는 코드가 순서를 가지기 때문이다. 단일 셀 하나만 보고 의미를 결정하지 않는다. 앞에 무엇이 왔느냐가 뒤의 해석을 바꾼다. 이것을 문맥 의존 해석(context-dependent interpretation)이라 한다.

코드 공간은 고정되어 있지만, prefix를 이용해 해석 모드를 전환함으로써 표현 가능한 범위를 넓힌다.
