# 인코더(Encoder) / 디코더(Decoder)

트랜스포머만의 개념이 아니라, 입력을 변환하고 출력을 생성하는 모든 시스템에서 쓰이는 일반적인 용어다.

## 어원

en-은 라틴어/프랑스어 접두사로 "안에 넣다", "~하게 만들다"는 의미다.
encode = en + code → "코드 안에 집어넣다" → 데이터를 특정 형식으로 변환하다.

de-는 "제거/되돌리기" 의미라서, encode(변환) ↔ decode(복원) 구조가 된다.
인코더가 텍스트를 벡터로 변환하고, 디코더가 벡터를 다시 텍스트로 변환하는 흐름이 어원과 정확히 일치한다.

## 인코더 — 압축하는 것

입력을 받아서 의미 있는 표현(벡터)으로 압축한다.
텍스트를 숫자 벡터로 변환하는 역할이다.
"이 문장의 의미를 내가 처리할 수 있는 형태로 바꾼다"는 개념이다.

## 디코더 — 풀어내는 것

압축된 표현을 받아서 다시 텍스트로 생성한다.
숫자 벡터를 텍스트로 변환하는 역할이다.
"벡터로 표현된 의미를 사람이 읽을 수 있는 형태로 복원한다"는 개념이다.

## 트랜스포머에서의 쓰임

트랜스포머는 인코더와 디코더를 각각 독립적으로 쓸 수 있다.
어느 쪽을 쓰느냐에 따라 모델의 성격이 달라진다.

1. **인코더만 사용 (BERT)** — 문장을 읽고 의미를 압축하는 데 특화. 텍스트를 생성하지 않는다. 분류·검색에 쓰인다.

2. **디코더만 사용 (GPT, Claude)** — 이전 토큰들을 참조해 다음 토큰을 생성하는 데 특화. 챗봇이 이 구조다.

3. **인코더 + 디코더 함께 사용 (번역 모델)** — 한국어를 인코더로 압축한 뒤, 디코더로 영어를 생성한다. 입력과 출력 언어가 다를 때 두 개를 같이 쓴다.
