# hexadecimal (16진수)

16을 기수로 하는 수 체계. 0~9에 A~F를 더해 16개 기호를 쓴다. 4비트가 정확히 16진수 한 자리에 대응되기 때문에 바이트를 간결하게 표현할 때 쓴다.

## 왜 8진수 대신 16진수인가

8진수(3비트 단위)는 바이트(8비트)와 딱 맞아 나뉘지 않는다. 8비트를 8진수로 표현하면 왼쪽 자리에 2비트, 나머지 두 자리에 3비트씩 배정된다. 멀티바이트 값을 8진수로 쓸 때 바이트 경계와 진수 자리 경계가 일치하지 않아 혼란스럽다.

16진수는 4비트 단위(nibble)로 딱 나뉜다. 1바이트 = 16진수 2자리. 바이트 경계와 진수 자리 경계가 항상 일치한다.

## 표기 방식

16진수는 A=10, B=11, C=12, D=13, E=14, F=15로 표기한다.

이진수 10110110을 16진수로 변환할 때는 오른쪽부터 4비트씩 묶는다.
- 1011 → B (11)
- 0110 → 6

결과: B6. 십진수로 182다.

멀티바이트도 같은 방식으로 바이트마다 16진수 두 자리로 변환하면 된다.
