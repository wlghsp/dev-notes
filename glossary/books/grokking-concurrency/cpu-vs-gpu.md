# CPU vs GPU

둘 다 수백만 개의 트랜지스터로 구성된 처리 장치지만, 설계 목표가 다르다.

## CPU

MIMD 아키텍처 기반. 소수의 강력한 코어가 고클럭으로 동작한다. 넓은 명령어 세트를 지원하므로 복잡하고 다양한 작업을 처리할 수 있다. 순차적 논리가 많은 일반 프로그램에 최적화돼 있다.

## GPU

SIMD 아키텍처 기반. 수백~수천 개의 단순한 코어가 저클럭으로 동작한다. 지원하는 명령어 세트가 매우 제한적이다. 하나의 명령어를 수천 개의 데이터에 동시 적용하는 방식으로 대규모 병렬 연산을 수행한다.

개별 코어 속도는 CPU가 빠르다. 하지만 GPU는 압도적인 코어 수로 병렬 연산 총량에서 CPU를 능가한다.

## 어떤 작업에 어느 쪽을?

GPU가 유리한 작업 — 같은 연산을 대량의 독립적인 데이터에 반복 적용하는 경우. 행렬 덧셈/곱셈, 이미지·영상 처리, 머신러닝 학습, 금융 시뮬레이션.

CPU가 유리한 작업 — 복잡한 분기와 다양한 명령어가 섞인 순차적 로직.

이 책에서는 CPU와 GPU를 구분하지 않고 "CPU"라는 단어를 두 종류 처리 자원을 포괄하는 의미로 사용한다.
