# 메타프로그래밍 (Metaprogramming)

메타프로그래밍은 프로그램이 다른 프로그램(또는 자기 자신)을 데이터처럼 다루면서 코드를 생성하거나 변형하는 것을 말한다. "코드를 작성하는 코드"라고 이해하면 된다.

컴파일러 맥락에서는 컴파일 타임에 코드를 생성하거나 검사하는 것을 가리키는 경우가 많다. 예를 들어 C++ 템플릿은 컴파일 타임에 타입별로 코드를 찍어내는 메타프로그래밍의 대표 사례이고, 이번 컨퍼런스의 다른 발표(옥찬호, "C++ Static Reflection")에서 다룬 정적 리플렉션도 컴파일 타임에 타입 정보를 코드가 스스로 들여다보고 그걸 바탕으로 새 코드를 생성한다는 점에서 메타프로그래밍의 한 형태다.

LLVM/MLIR 생태계에서는 다이얼렉트 정의나 변환 규칙 자체가 일종의 메타프로그래밍으로 볼 수 있다 — 컴파일러가 "어떤 연산을 어떻게 낮출지"를 기술한 규칙(코드)을 읽어서 실제 변환 코드를 생성하는 구조이기 때문이다.
