# twos-complement (2의 보수)

음수를 이진수로 표현하는 방식. 뺄셈을 덧셈 회로로 처리할 수 있게 해준다.

## 왜 필요한가

뺄셈은 빌림수(borrow) 방식으로 동작한다. 빌림수는 왼쪽에서 오른쪽으로 일관되게 흐르는 올림수와 달리 방향이 뒤섞여 회로로 만들기 까다롭다. 대신 뺄셈을 "음수를 더하는 것"으로 바꾸면 기존 덧셈 회로를 그대로 쓸 수 있다.

## 1의 보수에서 2의 보수로

10진수에서 9의 보수(nines' complement)를 구하듯이 2진수에서 1의 보수(ones' complement)를 먼저 이해해야 한다.

1의 보수는 단순히 모든 비트를 뒤집는 것이다. 11111101의 1의 보수는 00000010이다. 이것은 인버터(NOT 게이트)로 구현한다.

2의 보수는 1의 보수에 1을 더한 값이다. 8비트 기준으로 176(10110000)의 2의 보수:
1. 비트 반전: 01001111
2. 1을 더함: 01010000

이 값(01010000)을 253(11111101)에 더하면 100001101이 된다. 9번째 비트를 버리면 00001101, 즉 77이다. 253 - 176 = 77이 맞다.

## 회로에서의 구현

SUB 신호가 1이면 8개의 XOR 게이트가 B 입력 비트를 모두 반전시킨다. 동시에 SUB 신호가 덧셈기의 Carry In으로 들어가 1을 더해준다. 이렇게 하면 "1의 보수 + 1" = 2의 보수가 자동으로 완성된다. 별도 회로 없이 기존 8비트 덧셈기가 뺄셈도 처리한다.

## 표현 범위와 최상위 비트

8비트 2의 보수로 표현할 수 있는 범위는 -128부터 127이다. 최상위 비트(MSB)가 1이면 음수, 0이면 양수다. 128~255는 음수 공간에 해당한다.
