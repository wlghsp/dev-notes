# RAM 구조 (RAM Structure)

플립플롭(래치) 여러 개를 조합해서 만드는 읽기/쓰기 가능한 메모리. 각 래치에 주소를 부여하고 원하는 위치에 값을 저장하거나 읽을 수 있다.

## 1비트 래치에서 시작

D형 플립플롭의 Clock 입력을 Write로, Q 출력을 Data Out으로 이름을 바꾸면 1비트를 저장하는 래치가 된다. Write가 1일 때 Data In 값이 저장되고, Write가 0이 되면 그 값이 고정된다.

## 8비트 래치

1비트 래치 8개를 나란히 놓고 Write 신호를 공유하면 8비트 래치가 된다. 한 번에 8비트 값을 통째로 저장하거나 읽는다. 주소가 없기 때문에 저장할 수 있는 값은 단 하나다.

## 주소가 있는 RAM: 8×1 구성

8개의 1비트 래치를 각각 따로 쓰고 싶을 때 주소가 필요하다. 3비트 주소로 8개 래치 중 하나를 선택한다.

쓸 때는 3-to-8 Decoder가 Write 신호를 선택된 래치 하나에만 전달한다. 읽을 때는 8-to-1 Selector가 8개의 Data Out 중 주소에 해당하는 것만 출력으로 내보낸다. 주소 신호는 Decoder와 Selector 양쪽에 동시에 연결된다.

이 구성을 8×1 RAM이라 부른다. 8개의 주소에 각각 1비트 값을 저장할 수 있다.

## RAM 배열 확장

8×1 RAM 두 개를 같은 Address와 Write에 연결하되 Data In과 Data Out을 따로 두면 8×2 RAM이 된다. 8개의 주소에 각각 2비트 값을 저장할 수 있다.

반대로 주소를 늘리려면 8×1 RAM 두 개를 1-to-2 Decoder와 2-to-1 Selector로 연결해 16×1 RAM을 만든다. Select 입력이 사실상 네 번째 주소 비트가 된다.

저장할 수 있는 값의 개수는 주소 비트 수로 결정된다.

- 주소 비트 없음 → 1개
- 주소 1비트 → 2개
- 주소 2비트 → 4개
- 주소 3비트 → 8개
- 주소 n비트 → 2ⁿ개

## 랜덤 액세스의 의미

Random Access Memory라고 부르는 이유는, 어떤 주소든 순서 상관없이 바로 접근할 수 있기 때문이다. 주소 100을 읽으려고 주소 0~99를 먼저 읽을 필요가 없다.

## 킬로바이트

10개의 주소 입력이 있는 8비트 RAM은 2¹⁰ = 1024개의 주소를 가진다. 각 주소에 1바이트를 저장하므로 총 1024바이트, 즉 1킬로바이트(1KB)다.

1KB는 1000바이트가 아니라 1024바이트다. 2¹⁰ ≈ 10³ 이라는 근사값 때문에 kilo라는 접두사를 빌려 쓰는 것이다.
