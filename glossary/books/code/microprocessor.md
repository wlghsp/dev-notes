# microprocessor

마이크로프로세서는 CPU(Central Processing Unit)를 구성하는 모든 회로를 단일 실리콘 칩 위에 올린 집적회로다. 18장까지 릴레이, 게이트, 플립플롭, 가산기, RAM으로 쌓아온 모든 것이 이 하나의 칩 안에 들어간다.

## 탄생 배경

1971년 Intel이 4004를 출시하면서 시작됐다. 2300개의 트랜지스터로 만들어진 4비트 프로세서였다. 이전까지는 CPU를 여러 개의 IC 칩을 보드 위에 배선해서 구성했는데, 마이크로프로세서가 이것을 하나의 칩으로 압축했다.

## 마이크로프로세서를 비교하는 세 가지 기준

프로세서를 비교할 때 흔히 쓰는 세 숫자가 있다.

**1. 비트 폭 (data path width)**
한 번에 처리하는 데이터의 크기다. 4004는 4비트, 8080은 8비트다. 4비트 프로세서도 32비트 덧셈을 할 수 있다. 다만 4비트씩 나눠서 처리하므로 느릴 뿐이다. 비트 폭은 속도에 영향을 준다.

**2. 클럭 속도 (clock speed)**
프로세서를 구동하는 발진기의 최대 주파수다. 8080은 2MHz. 클럭 하나당 500나노초. 각 명령어는 4~18클럭이 필요하므로, 명령 하나에 2~9마이크로초가 걸린다. 클럭이 빠를수록 명령 실행도 빠르다.

**3. 주소 지정 가능한 메모리 크기 (addressable memory)**
주소 버스 폭이 결정한다. 8080은 16개의 주소 신호(A0~A15)를 가져서 2^16 = 65,536바이트, 즉 64KB를 주소로 가리킬 수 있다.

이 세 숫자는 프로세서의 *능력*이 아니라 *속도*에 관한 것이다. 4비트 프로세서가 할 수 없는 일을 8비트 프로세서가 할 수 있는 건 아니다. 어떤 프로세서든 결국 같은 계산을 한다. 차이는 얼마나 빨리 하느냐다.

## 마이크로프로세서 ≠ 컴퓨터

마이크로프로세서는 컴퓨터의 일부다. 최소한 다음이 함께 있어야 컴퓨터가 된다.

- 프로세서 (마이크로프로세서)
- RAM (프로그램과 데이터를 담는 공간)
- 입력 장치 (키보드 등)
- 출력 장치 (디스플레이 등)
- 이것들을 연결하는 주변 칩들
