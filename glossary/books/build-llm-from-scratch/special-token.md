# Special Token (특수 토큰)

특수 토큰은 일반 단어가 아닌, 모델에게 특정 문맥 정보를 전달하기 위해 추가하는 토큰이다. 어휘사전에 명시적으로 추가되고 고유한 ID를 갖는다.

> 📷 Figure 2.9 (책 p.29) — 기존 어휘사전에 `<|unk|>`(783)와 `<|endoftext|>`(784)가 추가되는 다이어그램

## 주요 특수 토큰

`<|unk|>` — 어휘사전에 없는 미등록 단어를 대체한다. 훈련 데이터에 없던 단어가 등장했을 때 사용한다. GPT 계열은 BPE를 사용해서 이 토큰이 필요 없다.

`<|endoftext|>` — 독립적인 텍스트 소스 사이의 경계를 표시한다. 여러 문서나 책을 연결해서 학습할 때, 각 소스 앞에 삽입해 서로 무관한 텍스트임을 LLM에 알린다.

> 📷 Figure 2.10 (책 p.30) — 독립된 4개 텍스트가 `<|endoftext|>`로 연결되어 하나의 스트림이 되는 다이어그램

`[BOS]` (beginning of sequence) — 텍스트 시작을 표시한다.

`[EOS]` (end of sequence) — 텍스트 끝을 표시한다. `<|endoftext|>`와 유사한 역할이다.

`[PAD]` (padding) — 배치 학습 시 길이가 다른 시퀀스를 같은 길이로 맞추기 위해 짧은 시퀀스를 채운다.

## GPT 계열의 선택

GPT 토크나이저는 `<|endoftext|>` 하나만 사용한다. 패딩에도 같은 토큰을 쓰지만, 배치 학습 시 마스크를 적용해 패딩 토큰이 손실 계산에 포함되지 않도록 한다. `<|unk|>`는 BPE로 대체되어 사용하지 않는다.
