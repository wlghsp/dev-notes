# Unix

**한 줄 정의**: 1969년 AT&T 벨 연구소에서 만든 운영체제. 현대 OS 대부분의 설계 뿌리다.

---

## 어디서 왔는가

1969년 켄 톰프슨(Ken Thompson)과 데니스 리치(Dennis Ritchie)가 AT&T 벨 연구소에서 만들었다. 처음에는 소규모 팀을 위한 작업용 OS였지만, 설계가 단순하고 이식성이 높아서 빠르게 퍼졌다.

C 언어도 유닉스를 만들기 위해 함께 탄생했다. 유닉스를 C로 다시 작성하면서 특정 하드웨어에 묶이지 않는 이식 가능한 OS가 됐다.

---

## 핵심 설계 철학

유닉스의 설계 원칙은 몇 가지로 요약된다.

**모든 것은 파일이다.** 디스크 파일뿐만 아니라 디바이스, 소켓, 프로세스 정보까지 파일 인터페이스로 다룬다. 읽고 쓰는 방식이 통일되기 때문에 도구들이 조합하기 쉽다.

**하나의 프로그램은 하나의 일만 잘 한다.** 작은 프로그램들을 파이프(`|`)로 연결해서 복잡한 작업을 처리한다. `ls | grep ".md" | wc -l` 같은 것이 이 철학의 산물이다.

**텍스트가 범용 인터페이스다.** 프로그램 간 데이터를 텍스트로 주고받는다. 파싱하기 쉽고 사람이 읽을 수 있다.

---

## 유닉스에서 비롯된 개념들

지금 당연하게 쓰는 것들 상당수가 유닉스에서 나왔다.

파일 디스크립터, fork/exec 프로세스 모델, `/etc` `/var` `/usr` 파일시스템 계층 구조, 파이프(`|`), 쉘(bash, zsh), 권한 모델(소유자/그룹/기타)이 전부 유닉스에서 설계됐다.

---

## 계보

유닉스 코드를 기반으로 파생된 OS들이 있고, 유닉스를 참고해서 새로 만든 OS들이 있다.

```
Unix (AT&T, 1969)
├── BSD (버클리 대학, 1977)
│   └── macOS (Apple, 2001~)  ← 공식 유닉스 인증 보유
└── System V
    └── 여러 상용 유닉스들

Unix를 참고해서 새로 만든 것:
└── Linux (리누스 토르발스, 1991)  ← 유닉스 코드 없음, 유닉스 호환
```

macOS는 실제 유닉스 혈통이라 "유닉스 기반"이라고 부른다. Linux는 유닉스 코드를 쓰지 않고 처음부터 다시 만들었지만 동작 방식이 유닉스와 호환되어서 "유닉스 계열(Unix-like)"이라고 부른다.
