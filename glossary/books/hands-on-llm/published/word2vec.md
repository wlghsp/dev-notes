# Word2Vec

단어를 고정된 크기의 벡터로 변환하는 임베딩 학습 방법이다.
2013년 Google이 발표했고, 현대 임베딩 기술의 출발점으로 평가받는다.

## 핵심 아이디어

단어의 의미는 그 단어 주변에 어떤 단어들이 등장하느냐로 결정된다는 분포 가설에 기반한다.
"비슷한 맥락에 등장하는 단어는 비슷한 의미를 가진다"는 것이다.

"고양이가 물을 마신다"와 "강아지가 물을 마신다"에서
'고양이'와 '강아지'는 비슷한 위치에서 비슷한 단어들과 함께 등장한다.
Word2Vec은 이 패턴을 학습해서 두 단어의 벡터를 가깝게 배치한다.

## 두 가지 학습 방식

**CBOW (Continuous Bag-of-Words)**
주변 단어들로 중간 단어를 예측한다.
"고양이가 ___ 마신다" → "물을" 예측.

**Skip-gram**
중간 단어로 주변 단어들을 예측한다.
"물을" → "고양이가", "마신다" 예측.
CBOW보다 느리지만 드물게 등장하는 단어에서 더 나은 결과를 보인다.

## 벡터 연산이 된다

학습된 벡터는 의미 관계를 수학적으로 표현한다.

```
king - man + woman ≈ queen
paris - france + italy ≈ rome
```

단어 간의 의미 관계가 벡터 공간에서 방향과 거리로 인코딩된 결과다.

## 한계

같은 단어는 항상 같은 벡터를 갖는다.

이 한계를 해결한 게 BERT 같은 문맥화 임베딩(Contextualized Embedding)이다.
