# 어휘 목록 (Vocabulary)

모델이 알고 있는 토큰의 전체 집합이다.
학습 전에 고정되고, 추론 시에도 변하지 않는다.

## 크기와 트레이드오프

어휘 목록이 크면 자주 등장하는 단어를 하나의 토큰으로 표현할 수 있어 시퀀스가 짧아진다.
대신 임베딩 레이어의 크기가 커지고 메모리 사용량이 늘어난다.

어휘 목록이 작으면 모델이 가볍지만, 모르는 단어를 더 잘게 쪼개야 해서 토큰 수가 늘어난다.
GPT-2는 약 50,000개, GPT-4는 약 100,000개의 어휘를 가진다.

## OOV (Out-Of-Vocabulary) 문제

단어 단위 토크나이저에서는 어휘 목록에 없는 단어를 처리할 수 없었다.
처음 보는 단어를 `[UNK]` 같은 특수 토큰으로 대체하면 의미를 잃는다.

BPE나 WordPiece 같은 서브워드 방식은 이 문제를 해결한다.
어떤 단어든 어휘 목록에 있는 서브워드 조각들로 분해할 수 있어 OOV가 발생하지 않는다.

## 특수 토큰

어휘 목록에는 일반 단어 외에 구조를 표현하기 위한 특수 토큰이 포함된다.

- `[CLS]` — 문장 시작. BERT에서 분류 태스크에 사용
- `[SEP]` — 문장 구분자. 두 문장을 이어붙일 때
- `[PAD]` — 배치 처리 시 길이를 맞추기 위한 패딩
- `[EOS]` / `<|endoftext|>` — 생성 종료 신호

참고: token.md, tokenization.md
