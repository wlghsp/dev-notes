# qps-estimation (QPS 추정 방법)

QPS(Queries Per Second)는 시스템이 초당 처리해야 하는 요청 수다. 봉투 뒷면 계산에서 가장 자주 등장하는 추정치이며, 이 값을 알아야 서버 대수나 캐시 용량 같은 후속 설계 결정을 내릴 수 있다.

## 계산 흐름

전체 사용자 수에서 시작해서 실제 요청을 만들어내는 활성 사용자, 그리고 사용자 한 명이 만드는 요청 수까지 단계적으로 좁혀나간다.

1. 일간 활성 사용자(DAU, Daily Active Users)를 구한다 — 전체 가입자 수 × 일간 사용 비율
2. DAU에 사용자 한 명당 평균 요청(예: 게시물 작성) 횟수를 곱한다
3. 하루 단위 값을 초 단위로 환산한다 — 하루는 24시간 × 3600초

## 예시: Twitter 트윗 작성 QPS 추정

가정: 월간 활성 사용자 3억 명, 그중 50%가 매일 Twitter를 사용, 사용자는 하루 평균 트윗 2개 작성.

1. DAU = 3억 × 50% = 1.5억
2. 트윗 QPS = 1.5억 × 2 / 24시간 / 3600초 ≈ 3,500
3. Peak QPS = 평균 QPS × 2 ≈ 7,000

평균 QPS만 보고 서버 용량을 정하면 트래픽이 몰리는 시간대에 장애가 난다. 그래서 평균값에 배수(보통 2배)를 곱한 Peak QPS를 기준으로 설계 여유를 둔다.
