# ALU (Arithmetic Logic Unit)

CPU 안에서 실제 연산을 처리하는 회로. CPU의 계산기 부분이다.

## 하는 일

크게 두 종류의 연산을 처리한다.

**산술 연산 (Arithmetic)**
- 덧셈, 뺄셈, 곱셈, 나눗셈

**논리 연산 (Logic)**
- AND, OR, NOT, XOR
- 비트 시프트 (<<, >>)

비교 연산(a > b, a == b)도 ALU가 처리한다. 내부적으로 뺄셈을 해서 결과가 0인지, 음수인지 확인하는 방식이다.

## 레지스터와의 관계

ALU는 직접 메모리에서 데이터를 가져오지 않는다. 레지스터에 있는 값을 받아서 연산하고, 결과를 다시 레지스터에 넣는다.

```
레지스터A ──┐
            ├──→ ALU → 결과 → 레지스터C
레지스터B ──┘
```

메모리 접근이 수백 클럭인데 ALU 연산 자체는 1 클럭 수준이다. ALU가 아무리 빨라도 메모리에서 데이터를 못 받으면 기다려야 한다. 캐시와 레지스터가 존재하는 이유다.

## 플래그 레지스터

ALU가 연산한 후 결과의 상태를 플래그 레지스터에 기록한다.

- Zero 플래그 — 결과가 0이면 1
- Carry 플래그 — 올림수(carry)가 발생하면 1
- Overflow 플래그 — 정수 오버플로우가 발생하면 1
- Sign 플래그 — 결과가 음수면 1

조건 분기(`if`, `while`)가 이 플래그를 보고 다음에 어느 명령어를 실행할지 결정한다. ALU가 비교 연산을 하면 → 플래그 레지스터에 결과 기록 → 제어 장치가 플래그를 보고 분기.

## 정수 산술과 오버플로우

ALU의 정수 연산은 고정된 비트 수(word size) 안에서 수행된다. 결과가 표현 범위를 넘으면 오버플로우가 발생한다. 이때 ALU는 Overflow 플래그를 세팅하고, 결과는 모듈러 산술(나머지 연산)로 잘린다.

unsigned 덧셈은 결과를 2^N으로 나눈 나머지다. 255 + 1 = 0 (8비트 기준). signed 덧셈 오버플로우는 C에서 undefined behavior다. 자세한 내용은 integer-overflow.md 참고.

## FPU (Floating Point Unit)

ALU는 정수 연산을 담당하고, 부동소수점 연산은 FPU라는 별도 회로가 처리한다. 현대 CPU는 FPU가 내장되어 있어서 따로 의식할 필요는 없지만, 부동소수점 연산이 정수 연산보다 느린 이유가 회로가 더 복잡하기 때문이다.
