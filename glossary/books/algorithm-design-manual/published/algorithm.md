# algorithm (알고리즘)

특정 문제를 해결하기 위한 명확하고 유한한 절차. 모든 가능한 입력 인스턴스에 대해 올바른 출력을 생성해야 한다.

알고리즘은 문제(problem)와 다르다. 문제는 입력과 출력의 명세이고, 알고리즘은 그 문제를 해결하는 구체적인 절차다. 하나의 문제에 여러 알고리즘이 존재할 수 있다.

좋은 알고리즘의 세 가지 조건:
1. correctness — 모든 인스턴스에서 올바른 답을 낸다
2. efficiency — 빠르게 동작한다
3. ease of implementation — 구현하기 쉽다

셋을 동시에 달성하기 어려운 경우가 많다. 실무에서는 충분히 좋은 답을 빠르게 내는 알고리즘이 이론적으로 최적인 알고리즘보다 선택되기도 한다.
