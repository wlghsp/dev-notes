# struct-memory (구조체의 메모리 레이아웃)

C의 struct는 필드들을 메모리에 순서대로 배치한다. 각 필드는 자신의 크기에 맞게 정렬(alignment)되어야 하기 때문에 필드 사이에 패딩(padding)이 생길 수 있다.

## 기본 레이아웃

```c
struct S {
    int   a;    // 4바이트, 오프셋 0
    char  b;    // 1바이트, 오프셋 4
    // 패딩 3바이트
    long  c;    // 8바이트, 오프셋 8
};              // 총 16바이트
```

`long c`는 8바이트 경계에 맞춰야 하므로 `char b` 뒤에 3바이트 패딩이 생긴다.

## 정렬(alignment) 규칙

각 타입은 자신의 크기의 배수 주소에 위치해야 한다.
- char: 1바이트 경계
- short: 2바이트 경계
- int, float: 4바이트 경계
- long, double, 포인터: 8바이트 경계

struct 자체도 가장 큰 필드의 크기에 맞춰 전체 크기가 결정된다.

## 필드 순서가 크기를 바꾼다

```c
struct Bad {
    char  a;    // 1바이트, 오프셋 0
    // 패딩 7바이트
    long  b;    // 8바이트, 오프셋 8
    char  c;    // 1바이트, 오프셋 16
    // 패딩 7바이트
};              // 총 24바이트

struct Good {
    long  b;    // 8바이트, 오프셋 0
    char  a;    // 1바이트, 오프셋 8
    char  c;    // 1바이트, 오프셋 9
    // 패딩 6바이트
};              // 총 16바이트
```

큰 필드를 앞에 배치하면 패딩이 줄어든다.

## 어셈블리에서의 접근

구조체 포인터에서 필드를 읽을 때 오프셋을 직접 더한다.
```asm
movl  4(%rdi), %eax    # struct 포인터 + 오프셋 4 = 두 번째 필드
movq  8(%rdi), %rax    # struct 포인터 + 오프셋 8 = 세 번째 필드
```

## union

같은 메모리 공간을 여러 타입으로 해석할 때 사용한다. 모든 필드가 오프셋 0에서 시작하고, union의 크기는 가장 큰 필드의 크기다.
