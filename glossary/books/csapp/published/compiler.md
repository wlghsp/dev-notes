# compiler

전처리된 C 소스를 어셈블리 코드로 변환하는 단계.

## 핵심 아이디어

사람이 읽을 수 있는 C 코드를 CPU가 이해할 수 있는 어셈블리 코드로 번역한다. 이 단계에서 코드의 의미를 분석하고 최적화한다.

## 하는 일

**구문 분석** — 소스 코드가 문법적으로 올바른지 확인한다. 오류가 있으면 여기서 컴파일 에러가 난다.

**최적화** — `-O2`, `-O3` 같은 옵션에 따라 코드를 더 빠르게 동작하도록 변환한다. 불필요한 연산을 제거하거나, 루프를 펼치거나, 레지스터를 효율적으로 배치한다.

**어셈블리 생성** — 대상 아키텍처(x86, ARM 등)에 맞는 어셈블리 코드를 만든다. 같은 C 코드도 아키텍처마다 다른 어셈블리가 나온다.

## 결과

확장자 `.s` 파일. 사람이 읽을 수 있는 어셈블리 코드.
