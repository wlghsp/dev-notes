# 고루틴과 코루틴

## 코루틴

실행을 중간에 멈추고, 나중에 그 지점부터 재개할 수 있는 함수다.

```python
def counter():
    yield 1
    yield 2
    yield 3

gen = counter()
next(gen)  # 1
next(gen)  # 2
```

`yield` 시점에 멈추고, 다음 호출 때 그 다음 줄부터 실행된다.

특정 언어의 기능이 아니라 프로그래밍 전반에서 쓰이는 **범용 개념**이다.  
Python의 `yield`, JavaScript의 `async/await`, Kotlin의 `suspend fun` 모두 코루틴이다.

> **Kotlin 코루틴(`kotlinx.coroutines`)은 이 개념의 구현체 중 하나다.**  
> `CoroutineScope`, `Dispatcher`, `Job` 등을 갖춘 라이브러리로, 코루틴을 가장 정교하게 구현한 사례지만 코루틴 그 자체는 아니다.  
> "코루틴 = Kotlin 것"으로 알기 쉬운 이유는 Kotlin이 유독 "코루틴"이라는 이름을 전면에 내세웠기 때문이다.

코루틴은 **스스로 제어권을 넘긴다.** 직접 `yield`/`await`를 써야 다른 코루틴이 실행된다.

## 고루틴

Go 언어의 경량 실행 단위다. `go` 키워드 하나로 실행한다.

```go
go func() {
    fmt.Println("hello")
}()
```

코루틴에서 출발했지만 두 가지가 다르다.

**선점적 스케줄링** — 코루틴은 스스로 yield해야 제어권이 넘어간다. 고루틴은 Go 런타임이 알아서 전환한다. yield 같은 걸 쓸 필요가 없다.

**진짜 병렬 실행** — 코루틴은 싱글스레드에서 번갈아 실행된다. 고루틴은 여러 CPU 코어에서 동시에 실행된다.

```
고루틴 수백만 개
      ↓  Go 런타임 스케줄러
OS 스레드 수십 개
      ↓
CPU 코어 (병렬 실행)
```

OS 스레드보다 훨씬 가볍다. 초기 스택이 2KB라 수백만 개도 거뜬하다.

---

## 한 줄 정리

- **코루틴**: "실행을 멈추고 재개한다" — 언어 전반에서 쓰이는 범용 개념
- **고루틴**: 코루틴에서 출발해, 런타임이 스케줄링하고 멀티코어까지 활용하는 Go의 구현
