# parity
참고: raid.md

---

데이터 손실 시 복구할 수 있도록 미리 계산해둔 체크값이다.

원리는 XOR 연산이다. XOR은 같은 비트면 0, 다른 비트면 1을 반환한다. 그리고 "A XOR B = C"이면 "C XOR B = A"가 성립한다. 이 성질 덕분에 나머지 값들을 전부 XOR하면 잃어버린 값을 되돌릴 수 있다.

예를 들어 디스크 A에 `1010`, 디스크 B에 `1100`이 있으면 패리티는 `0110`이다. 디스크 A가 죽으면 패리티 XOR B = `0110` XOR `1100` = `1010`으로 A를 복구한다.

미러링과 비교하면 차이가 명확하다. 미러링은 데이터 전체를 그대로 복제하므로 저장 용량이 두 배 필요하다. 패리티는 복구에 필요한 최소한의 정보만 저장하므로 용량 효율이 더 높다. 대신 복구 시 계산 과정이 필요하다.

RAID 5는 패리티를 별도 디스크 하나에 몰아두지 않고 여러 디스크에 분산시킨다. 패리티 디스크 하나가 쓰기 병목이 되는 문제를 막기 위해서다. RAID 6는 패리티를 두 개 계산해서 디스크 2개가 동시에 죽어도 복구 가능하게 한다.
