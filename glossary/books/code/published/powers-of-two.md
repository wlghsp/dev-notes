# powers-of-two (2의 거듭제곱)

2를 반복해서 곱한 값들. 이진 시스템 어디서나 등장한다.

## 값 목록

2¹ = 2
2² = 4
2³ = 8
2⁴ = 16
2⁵ = 32
2⁶ = 64
2⁷ = 128
2⁸ = 256
2¹⁰ = 1,024 (≈ 1K)
2²⁰ = 1,048,576 (≈ 1M)
2³⁰ = 1,073,741,824 (≈ 1G)

## 왜 자꾸 등장하는가

이진 시스템에서 자리 수가 하나 늘 때마다 표현 범위가 2배가 된다. 그래서 비트 수, 메모리 크기, 캐시 크기, 주소 범위 등 컴퓨터의 거의 모든 수치가 2의 거듭제곱으로 표현된다.
