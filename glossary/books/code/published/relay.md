# relay (릴레이)

릴레이는 약한 입력 전류로 강한 출력 전류를 제어하는 전자기 스위치다. 사람 손이 아니라 전류가 스위치를 켜고 끈다.

## 동작 원리

입력 전류가 전자석 코일에 흐르면 자성이 생긴다. 자성이 유연한 금속 띠를 끌어당기면, 그 금속 띠가 출력 회로의 스위치를 닫는다. 입력 전류가 끊기면 자성이 사라지고 금속 띠가 원래 위치로 돌아가 출력 회로를 다시 열린 상태로 만든다.

입력 → 전자석 동작 → 금속 띠 이동 → 출력 스위치 on/off

## 장거리 전신에서의 역할

전선은 길어질수록 저항이 커지고 신호가 약해진다. 300마일이 넘으면 전류가 너무 약해져 소더를 작동시키지 못한다.

릴레이를 중간에 설치하면 약해진 신호로 릴레이를 작동시키고, 릴레이가 새 배터리에 연결된 강한 출력 회로를 켠다. 신호가 죽지 않고 이어진다.

## 왜 더 중요한가

릴레이는 단순한 신호 증폭 장치가 아니다. 전류로 스위치를 제어할 수 있다는 사실은, 전류들을 조합해 논리 연산을 할 수 있다는 가능성을 열어준다. 이것이 논리 게이트와 컴퓨터로 이어지는 출발점이다.
