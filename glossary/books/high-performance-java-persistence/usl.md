# usl (Universal Scalability Law)

동시성 수준(N)이 늘어날 때 시스템의 상대적 처리량 증가가 어떻게 꺾이는지를 설명하는 공식.

## 왜 필요한가

이상적으로는 데이터베이스 커넥션(로드 생성기)을 늘리면 처리량도 그만큼 비례해서 늘어야 한다. 하지만 실제로는 공유 자원 경합(contention)과 여러 세션 간 일관성 유지 비용(coherency) 때문에 처리량 증가 곡선이 꺾인다. USL은 이 꺾이는 지점까지 정량적으로 근사한다.

## 공식

C(N) = N / (1 + α(N-1) + βN(N-1))

- C — 주어진 동시성 수준에서의 상대적 처리량 증가율
- α — contention 계수. 처리 로직 중 직렬화(순차 처리)될 수밖에 없는 비율
- β — coherency 계수. 동시 세션 간 일관성을 유지하는 데 드는 비용

α만 있고 β가 0이면 USL은 암달의 법칙(Amdahl's Law)과 같아진다. contention은 확장성을 서서히 평평하게 만들고, coherency는 곡선에 변곡점을 만들어 N이 커질수록 오히려 처리량을 떨어뜨린다.

## 최대 동시성 지점

시스템이 최대 용량에 도달하는 동시성 수준은 계수만으로 계산된다.

Nmax = sqrt((1-α) / β)

이 지점을 넘어서 커넥션을 더 늘리면 처리량은 오히려 감소한다. 즉 "커넥션을 더 열면 더 빨라진다"는 직관이 항상 맞지 않는다는 근거가 된다.
