# Mojo

Mojo는 Modular사가 만든 프로그래밍 언어로, Python과 문법 호환성을 유지하면서 MLIR 위에서 컴파일되어 네이티브 코드 수준의 성능을 내는 것을 목표로 한다.

기존 Python은 인터프리터 기반이라 느리고, 성능이 필요한 부분(딥러닝 커널 등)은 결국 C/C++이나 CUDA로 따로 작성해야 했다. Mojo는 Python 문법을 그대로 쓰면서도 정적 타입, 컴파일 타임 최적화, 하드웨어별(CPU, GPU 등) 코드 생성을 지원해서 이 이중 언어 문제를 없애려 한다.

이게 가능한 이유가 MLIR이다. Mojo 컴파일러는 소스 코드를 MLIR의 다이얼렉트로 낮추고, 이 다이얼렉트가 다시 여러 층위를 거쳐 특정 하드웨어에 맞는 코드로 변환된다. 즉 LLVM만으로는 Python 같은 고수준 동적 언어의 의미를 저수준 최적화에 활용하기 어려운데, MLIR이 그 중간 층위 역할을 해주면서 Mojo가 가능해진 것이다.
