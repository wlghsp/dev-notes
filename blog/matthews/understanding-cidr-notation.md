# IP 주소 뒤의 /숫자, CIDR

## CIDR란?

IP 주소 뒤에 `/24`, `/16`처럼 슬래시와 숫자가 붙는 표기법을 CIDR(사이더)라고 한다.

## IP 주소의 이해

IP 주소는 점으로 나뉜 4개의 영역으로 되어 있고, 각 자리는 0~255까지, 즉 1바이트(8비트)를 차지한다. 8비트는 2^8 = 256가지 조합을 표현할 수 있고, 1바이트는 옥텟(octet)이라고도 부른다.

```
1 byte = 8 bit = 1 octet
```

IP 주소를 문자열로 표현하면 `255.255.255.255`처럼 15바이트가 필요하지만, IPv4는 4바이트의 2진 표현으로 이를 축약한다. 모든 패킷에 IP 주소가 반복적으로 붙기 때문에, 이렇게 최소한의 용량으로 표현하는 것이 중요하다.

## CIDR 숫자의 이해

`0.0.0.0/24`는 `0.0.0.0`이라는 IP 주소의 전체 32비트(8비트 × 4) 중 앞에서부터 24비트를 mask한다는 뜻이다. 32비트 중 앞의 24비트(8+8+8)를 가리면, 마지막 8비트, 즉 마지막 자리만 남는다.

즉 `/24`는 32비트 중 앞의 24비트를 고정하고, 남은 8비트만 값이 바뀔 수 있다는 뜻이다. 바뀔 수 있는 부분이 곧 그 CIDR가 나타내는 IP 범위가 된다.

- `192.168.0.1/24`는 앞의 `192.168.0`은 고정, 마지막 자리(8비트, 0~255)만 바뀔 수 있으므로 `192.168.0.0` ~ `192.168.0.255`까지 총 256개의 IP 범위를 뜻한다.
- `192.168.0.0/16`은 앞의 절반(16비트)만 고정되므로 `192.168.0.0` ~ `192.168.255.255`까지를 뜻한다.

## 서브넷 마스크(Subnet Mask)

서브넷은 네트워크를 그룹으로 묶은 작은 네트워크다. 서브넷이 가질 수 있는 IP 범위를 표현할 때도 CIDR 표기법을 쓴다. 그 범위의 IP를 가진 디바이스끼리 통신을 담당하는 것이 서브넷의 역할이다.

AWS에서 VPC를 만들 때 IP 범위 지정에 CIDR가 쓰이며, 보통 `172.31.0.0/16` 같은 대역을 사용한다.

## Private IP 예약 주소 대역

전 세계 어디에도 공인 IP로 할당되지 않고, 사설 용도로만 예약된 대역이 세 가지 있다.

- `10.0.0.0` ~ `10.255.255.255` (CIDR로는 `10.0.0.0/8`)
- `172.16.0.0` ~ `172.31.255.255`
- `192.168.0.0` ~ `192.168.255.255`

## 마무리

CIDR 계산이 번거롭다면 CIDR 계산기를 검색해서 사용하면 된다.
