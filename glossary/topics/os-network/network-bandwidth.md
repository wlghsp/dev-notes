# 네트워크 대역폭 (Network Bandwidth)

네트워크 장비나 인터페이스가 초당 전송할 수 있는 데이터 양이다. 단위는 bps(bits per second).

```
1Gbps  = 초당 1기가비트
10Gbps = 초당 10기가비트
25G, 100G = 데이터센터 서버 간 고속 연결
```

비트 단위라서 실제 처리량(MB/s)으로 환산하려면 8로 나눈다.

```
1Gbps  → 약 125MB/s
10Gbps → 약 1.25GB/s
```

## 어디서 보이나

**서버 NIC (Network Interface Card)**
서버에 꽂힌 네트워크 카드의 속도다. AWS EC2 인스턴스 스펙에 "최대 25Gbps 네트워크 대역폭" 같은 표기가 이거다. 인스턴스 타입이 클수록 대역폭이 높다.

**스위치 포트**
서버실 스위치가 1G짜리면 서버 NIC가 아무리 빨라도 1G 이상 나오지 않는다. 병목이 스위치에 있는 경우다.

**RDS / ElastiCache**
인스턴스 타입마다 네트워크 대역폭이 다르다. 쿼리가 많아지면 CPU보다 네트워크 대역폭이 먼저 병목이 되기도 한다.

## 병목 확인

CPU, 메모리만 보다가 NIC 대역폭이 포화된 경우를 놓치는 경우가 있다.

```bash
# 네트워크 인터페이스별 사용량 확인
iftop

# 프로세스별 네트워크 사용량
nethogs

# 간단하게 인터페이스 통계
ip -s link
```

대역폭이 한계에 가까워지면 처리량은 그대로인데 지연(latency)이 급격히 늘어난다.
