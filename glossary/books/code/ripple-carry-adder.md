# ripple-carry-adder (리플 올림수 덧셈기)

전가산기 여러 개를 직렬로 연결해서 여러 비트 덧셈을 처리하는 회로. 각 자리의 Carry Out이 다음 자리의 Carry In으로 "흘러 들어가는(ripple)" 구조다.

## 동작 방식

8비트 덧셈기를 예로 들면 전가산기 8개를 연결한다.

- 맨 오른쪽(0번째 자리): Carry In = 0(접지). A0과 B0을 더해 S0과 Carry Out을 출력한다.
- 1번째 자리: 0번째 자리의 Carry Out이 이 자리의 Carry In이 된다. A1, B1, Carry In을 더한다.
- 이 방식으로 7번째 자리까지 이어진다. 마지막 Carry Out은 9번째 비트(오버플로우)가 된다.

8비트 덧셈기 전체는 릴레이 144개로 구성된다. 전가산기 하나가 18개, 8개이니 144개.

## 리플의 의미와 한계

"리플"이라는 이름이 붙은 이유는 올림수가 왼쪽으로 순차적으로 전파되기 때문이다. 0번째 자리 계산이 끝나야 1번째 자리 계산을 시작할 수 있고, 이 지연이 비트 수만큼 쌓인다.

덧셈기 전체의 속도는 전가산기 하나의 속도 × 비트 수다. 비트 수가 많아질수록 느려진다.

더 빠른 방식으로 look-ahead carry(선행 올림수) 방식이 있다. 각 자리의 올림수를 미리 병렬로 계산해서 기다리지 않는다. 회로가 복잡해지지만 속도가 훨씬 빠르다.
