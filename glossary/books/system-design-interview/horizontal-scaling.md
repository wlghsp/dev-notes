# horizontal-scaling (수평 확장)

Scale Out이라고도 부른다. 서버를 더 추가해서 자원 풀을 늘리는 방식. 대규모 애플리케이션에서 수직 확장의 한계를 극복하기 위해 사용한다.

## 수직 확장과의 차이

수직 확장은 한 서버를 더 강하게 만든다. 수평 확장은 서버를 더 많이 추가한다. 수평 확장은 서버 한 대가 죽어도 나머지가 트래픽을 받을 수 있어 이중화(Redundancy)가 자연스럽게 생긴다.

## 로드 밸런서와의 조합

수평 확장을 하면 사용자가 어느 서버로 요청을 보낼지 결정해야 한다. 이 역할을 로드 밸런서가 담당한다. 로드 밸런서가 없으면 서버를 여러 대 두더라도 트래픽을 고르게 나눌 수 없다.

## 웹 티어 vs 데이터 티어

웹 서버는 상태(State)를 외부로 분리하면 수평 확장이 쉽다(Stateless 아키텍처). 데이터베이스의 수평 확장은 샤딩(Sharding)이라 부르며 구현 복잡도가 더 높다.
