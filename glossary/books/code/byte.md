# byte (바이트)

8비트를 하나의 단위로 묶은 것. 컴퓨터 내부에서 데이터를 다루는 기본 단위다.

## 왜 8비트인가

8이라는 숫자가 처음부터 필연적이었던 건 아니다. 12장의 이진 덧셈기를 8비트로 설계한 것이 편의상의 선택이었고, 그것이 자연스럽게 굳어졌다. IBM이 1956년경 byte라는 단어를 만들었으며, 1960년대 중반 System/360 설계를 거치며 8비트가 표준이 됐다.

## 표현 범위

8비트이므로 2⁸ = 256가지 값을 표현할 수 있다.

부호 없는 정수로 쓰면 0~255다. 2의 보수(twos-complement-code.md)로 쓰면 -128~127이다.

8비트 = 256가지라는 수가 유용한 이유는 여러 곳에서 등장한다. 대부분의 자연어(중국어, 일본어, 한국어의 표의문자 제외) 문자를 256개 안에 표현할 수 있고, 흑백 사진의 회색 농도도 사람 눈이 구분하는 범위가 약 256단계다.

## nibble

4비트는 nibble(니블)이라 부른다. 1바이트 = 2니블. 16진수 한 자리가 정확히 4비트(nibble)에 대응된다. 이 때문에 바이트를 16진수 두 자리로 표현하면 딱 맞아떨어진다.
