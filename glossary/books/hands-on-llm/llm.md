# LLM (Large Language Model)

텍스트를 이해하거나 생성하도록 방대한 양의 텍스트 데이터로 학습된 모델이다.
"Large"는 모델의 파라미터 수와 학습 데이터 규모를 가리키는데, 그 경계는 시대에 따라 계속 이동하기 때문에 고정된 기준은 없다.

LLM은 크게 두 가지 방향으로 나뉜다.

1. **Representation Model (표현 모델)** — 텍스트를 숫자 벡터로 변환하는 데 특화. 텍스트를 생성하지 않고, 분류·검색·클러스터링 등 태스크에 쓰인다. BERT가 대표적이다.

2. **Generative Model (생성 모델)** — 텍스트를 생성하는 데 특화. 주어진 입력에 이어지는 텍스트를 예측하는 방식으로 동작한다. GPT 계열, ChatGPT가 대표적이다.

## 학습 방식

LLM은 다음 토큰을 예측하는 태스크로 사전학습(pretraining)된다.
모델이 "다음 단어가 무엇인가"를 반복적으로 맞추는 과정에서 언어의 패턴과 의미 관계를 내재화한다.
파라미터 수가 많을수록 더 복잡한 패턴을 포착할 수 있다.

## 왜 중요한가

LLM 이전까지 AI가 언어를 다루는 방식은 규칙 기반이거나 통계 기반이었다.
LLM은 언어를 "이해"하는 것처럼 보이는 수준의 일반화 능력을 보여줬고,
번역, 요약, 코드 생성, 질문 답변 등 기존에 각각 별도 모델이 필요했던 태스크를 하나의 모델로 처리할 수 있게 됐다.
