# bus

버스(bus)는 컴퓨터 내부의 여러 구성 요소를 연결하는 공유 신호선의 집합이다. CPU, RAM, 입출력 장치가 동일한 신호선을 공유하고, 한 번에 하나의 장치만 데이터를 내보낸다.

## 버스를 구성하는 네 가지 신호

**주소 신호 (Address signals)**
CPU가 내보내는 출력 신호. RAM의 특정 위치나 연결된 다른 장치를 가리키는 데 쓴다. 8080은 A0~A15로 16개의 주소 신호를 가진다. 16비트 주소이므로 64KB를 가리킬 수 있다.

**데이터 출력 신호 (Data Output signals)**
CPU가 메모리나 장치에 쓸 데이터를 내보내는 신호. 8비트 프로세서는 8개의 데이터 신호를 갖는다.

**데이터 입력 신호 (Data Input signals)**
RAM이나 다른 장치가 CPU에게 데이터를 보내는 신호. 8080에서는 데이터 입력과 출력이 같은 핀을 공유하고, 읽기/쓰기 방향은 R/W 제어 신호로 구분한다.

**제어 신호 (Control signals)**
읽기/쓰기 여부, 인터럽트, 버스 사용권 등을 알리는 신호들. 프로세서 종류마다 다르다.

## 버스에 여러 장치를 연결하는 방법

64KB 주소 공간에 4KB RAM 보드를 꽂는다고 하면, 같은 버스에 여러 장의 메모리 보드를 연결해야 한다. 이때 각 보드는 자기에게 할당된 주소 범위에만 반응해야 한다.

상위 주소 비트(A12~A15)를 DIP 스위치로 설정해두면, 비교기(comparator) 회로가 버스의 주소 신호와 스위치 설정값을 비교한다. 일치할 때만 해당 보드의 CS(Chip Select) 신호가 활성화된다. CS가 비활성화된 보드는 데이터 출력을 tri-state(고임피던스 상태)로 전환해서 버스에 영향을 주지 않는다.

tri-state 출력이 없으면 여러 장치의 출력이 버스에 동시에 연결될 때 충돌이 발생한다. 버스 연결이 가능한 이유는 활성화되지 않은 장치가 전기적으로 연결을 끊는 tri-state 덕분이다.

## 오픈 아키텍처와 버스 표준

버스 규격을 공개하면 다른 제조사도 그 버스에 맞는 확장 보드를 만들 수 있다. 이것이 오픈 아키텍처다.

1975년 Altair 8800과 함께 등장한 S-100 버스가 초기 홈 컴퓨터의 표준이었고, IBM PC(1981)의 ISA 버스, 이후 EISA, PCI로 이어졌다. IBM이 원래 PC의 기술 명세를 공개한 덕분에 수많은 클론 제조사가 생겨났고, 호환 PC가 시장 90%를 차지하게 됐다.

반대로 Apple Macintosh는 클로즈드 아키텍처로 시작했고, 이것이 시장 점유율에 영향을 줬다는 시각도 있다.
