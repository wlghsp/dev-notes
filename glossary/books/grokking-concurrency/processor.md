# Processor

CPU(Central Processing Unit). 프로그램의 기계 명령어를 해석하고 실행하는 하드웨어 장치.

## 구성 요소

CPU는 두 핵심 부품으로 이루어진다.

1. **CU (Control Unit)** — 기계 명령어를 해석하고, 어떤 처리 장치로 보낼지 결정한다. CPU의 지휘관 역할.
2. **ALU (Arithmetic Logic Unit)** — 산술 연산과 비트 연산을 수행한다. 실제 계산을 담당하는 부품.

이 두 부품 외에 캐시도 CPU의 핵심 구성 요소다. CPU는 RAM에 직접 접근하지 않고 캐시를 경유한다.
