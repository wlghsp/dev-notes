### 짚어볼 점 — "PR 링크가 없다"는 지적의 구조적 문제

1차 리뷰가 지적한 "제출 증거에 PR 링크가 없다"는 항목은 **최초 제출 시점에는 원천적으로 충족 불가능한 요건**이었다. evidence 파일은 PR을 열기 전에 같은 브랜치에 커밋되는 파일이고, PR 자체가 그 브랜치를 기반으로 생성되는 것이므로, 최초 커밋 시점엔 PR 번호도 URL도 존재할 수 없다 (PR을 열어야 번호가 생기는데, PR을 열려면 evidence가 먼저 커밋돼 있어야 하는 순환 구조).

missions/README.md 공통 제출 계약 5번("PR 자동 검사와 AI 리뷰를 확인합니다. 보완 요청이 있으면 같은 PR에 수정 커밋을 push하고...")을 보면, "PR 링크"는 최초 제출 때 채우라는 게 아니라 **PR이 이미 존재하는 재제출(리뷰 반영) 단계에서** 채우는 항목으로 보는 게 합리적이다. 실제로 이번에도 PR #1이 이미 열린 상태에서 evidence를 수정해 링크를 채웠다. 처음부터 이 요건을 완벽히 채우는 방법은 없고, "PR 생성 후 채움"이라고 비워두는 게 최초 제출 시점의 정직한 접근이다.
