# pixel (픽셀)

픽셀(pixel)은 picture element의 줄임말이다. 화면을 구성하는 최소 단위의 점이다.

## 래스터 디스플레이

오늘날 PC 모니터는 래스터 디스플레이(raster display)다. 화면을 픽셀의 2차원 배열로 표현하고, 각 픽셀 값을 메모리에 저장해서 화면을 구성하는 방식이다.

책이 쓰인 2000년 기준에는 CRT(브라운관) 모니터가 주류였다. CRT는 전자총이 화면을 가로로 빠르게 훑으며(raster line) 위에서 아래로 내려가는 방식으로 픽셀을 그렸다. 현대의 LCD나 OLED는 전자총 없이 액정이나 유기물로 픽셀을 직접 켜는 방식이라 동작 원리는 다르다. 하지만 픽셀 배열 구조와 비디오 메모리에 픽셀 값을 저장하는 원리는 동일하다.

화면은 픽셀의 2차원 배열이다. 일반적인 해상도는 가로 640, 세로 480 픽셀이다. 총 픽셀 수는 640 × 480 = 307,200개다.

## 픽셀과 메모리

화면의 모든 픽셀 값은 메모리에 저장된다. 이 영역을 비디오 디스플레이 메모리라 한다. 프로세서의 주소 공간에 직접 매핑되어 있어, 그 주소에 값을 쓰면 화면이 바뀐다.

픽셀 하나에 할당되는 비트 수가 표현 가능한 색의 수를 결정한다.

- 1비트/픽셀: 흑백 2색
- 3비트/픽셀: 8색 (RGB 각 1비트)
- 2바이트/픽셀: 32,768색 (하이컬러, thousands of colors)
- 3바이트/픽셀: 16,777,216색 (풀컬러, millions of colors)

색의 수 = 2^(비트 수)

## 컬러 원리

CRT 모니터는 세 종류의 전자총을 쓴다. 빨강(Red), 초록(Green), 파랑(Blue)이다. 이 세 원색을 더하는 방식(가산 혼합)으로 다양한 색을 만든다. 빨강 + 초록 = 노랑, 빨강 + 파랑 = 마젠타, 초록 + 파랑 = 시안, 셋 다 = 흰색이다.

## 해상도와 메모리 요구량

640×480 풀컬러(3바이트/픽셀) 화면을 저장하려면 640 × 480 × 3 = 921,600바이트, 약 1MB가 필요하다. 해상도나 색 깊이를 높이면 메모리 요구량이 급증한다. 비디오 어댑터 보드에 탑재된 메모리 용량이 지원 가능한 해상도와 색 깊이의 조합을 결정한다.
