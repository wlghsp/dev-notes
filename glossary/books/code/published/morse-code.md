# morse-code (모스 부호)

점(dot)과 대시(dash) 두 가지 신호만으로 모든 문자를 표현하는 코드. 이진 코드의 원형이다.

## 설계 원칙

자주 쓰는 문자일수록 짧은 코드를 배정했다. E는 점 하나(·), T는 대시 하나(—). 드문 문자(Q, Z)는 길다. 정보 효율을 높이기 위한 선택이다.

## 동작 방식

점과 대시를 조합해서 문자를 표현한다. 플래시라이트로 보내면 짧은 깜빡임이 점, 긴 깜빡임이 대시다. 글자 사이에는 짧게 쉬고, 단어 사이에는 더 길게 쉰다.
