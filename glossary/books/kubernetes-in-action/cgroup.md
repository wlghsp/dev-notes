# cgroup (Control Groups)
참고: linux-namespace.md

---

Linux 커널 기능으로, 프로세스(또는 프로세스 그룹)의 리소스 사용량을 제한하고 측정한다. 네임스페이스가 "무엇을 볼 수 있는가"를 제어한다면, cgroup은 "얼마나 쓸 수 있는가"를 제어한다.

네임스페이스만으로는 한 컨테이너가 CPU를 100% 점유하거나 메모리를 전부 사용하는 것을 막을 수 없다. cgroup이 이 역할을 한다.

## 제한 대상

- CPU — 사용할 코어 지정(`--cpuset-cpus`), 사용 비율 제한(`--cpus`)
- Memory — 최대 메모리 크기(`--memory`), swap 제한 등
- 네트워크 대역폭, 디스크 I/O 등

Docker의 `--memory`, `--cpus` 같은 옵션들은 내부적으로 cgroup 설정을 통해 동작한다. 실제 제한은 커널이 수행한다.

## 컨테이너 격리의 두 축

컨테이너 격리는 네임스페이스와 cgroup이 함께 담당한다.
- 네임스페이스 — 프로세스가 볼 수 있는 자원의 범위를 제한 (격리)
- cgroup — 프로세스가 사용할 수 있는 자원의 양을 제한 (제어)
