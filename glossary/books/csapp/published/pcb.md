# pcb (Process Control Block)

OS가 프로세스 하나를 관리하기 위해 유지하는 자료구조. 프로세스당 하나씩 존재하며, 커널 메모리에 저장된다.

## 무엇을 담는가

context-switch가 일어날 때 CPU 상태를 여기에 저장하고, 다시 실행할 때 여기서 복원한다.

주요 항목:
- 프로세스 ID (PID)
- 프로세스 상태 — running, ready, waiting 등
- 프로그램 카운터 (PC) — 다음에 실행할 명령어 주소
- CPU 레지스터 전체 — 범용 레지스터, 스택 포인터 등
- 메모리 매핑 정보 — 페이지 테이블 포인터
- 열린 파일 목록, 시그널 정보 등

## context-switch에서의 역할

프로세스 A → 프로세스 B로 전환할 때:

1. 현재 CPU 상태를 A의 PCB에 저장
2. B의 PCB에서 저장된 상태를 CPU에 복원
3. B가 이전에 멈췄던 지점부터 이어서 실행

PCB가 없으면 멈췄다가 다시 돌아왔을 때 어디서 뭘 하던 중이었는지 알 수 없다.

## 스레드와의 차이

스레드는 PCB 대신 TCB(Thread Control Block)를 가진다. TCB는 PC와 레지스터만 저장하고, 메모리 매핑 정보는 같은 프로세스의 PCB를 공유한다. 이 때문에 스레드 전환이 프로세스 전환보다 비용이 낮다.
