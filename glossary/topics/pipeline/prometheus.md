# Prometheus

Prometheus는 메트릭을 수집하고 저장하는 시계열 데이터베이스이자 모니터링 시스템이다.

## Pull 방식으로 수집한다

Prometheus는 대상 시스템이 데이터를 밀어넣는 게 아니라, Prometheus가 직접 대상의 `/metrics` HTTP 엔드포인트를 주기적으로 긁어온다(scrape). 그래서 이 방식을 pull 모델이라고 부른다.

Pull 모델은 몇 가지 이점이 있다. Prometheus가 스크래핑 주기를 직접 통제하기 때문에 대상이 죽었는지 여부를 스크래핑 실패로 바로 감지할 수 있다. 또한 대상 애플리케이션은 `/metrics` 엔드포인트만 노출하면 되고, 모니터링 서버의 위치나 인증 정보를 알 필요가 없다.

## 저장 구조

수집한 데이터는 Prometheus 자체 시계열 데이터베이스(TSDB)에 저장된다. 각 메트릭은 이름과 레이블(label, key-value 쌍)의 조합으로 식별되는데, 이 다차원 모델 덕분에 별도의 메트릭 이름을 늘리지 않고도 레이블 조합만으로 세밀하게 필터링하고 집계할 수 있다.

TSDB는 기본적으로 로컬 디스크에 데이터를 쓴다. 그래서 보관 기간이 길어지면 디스크 용량 문제가 생기는데, 이 한계를 풀어주는 레이어가 thanos.md다.

## 커뮤니케이션에서 헷갈리는 지점

Prometheus는 단일 노드로 동작하도록 설계된 도구라, 여러 클러스터나 여러 인스턴스의 데이터를 하나로 묶어서 보는 기능은 원래 없다. 이 통합 조회와 장기 보관을 해주는 게 Thanos다.
