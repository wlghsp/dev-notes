# 카운터 (Counter)

클럭 신호에 따라 값이 자동으로 증가하는 회로. 플립플롭 여러 개를 직렬로 연결해서 만든다.

## 기본 동작

edge-triggered D형 플립플롭의 Q-bar 출력을 다음 플립플롭의 Clock 입력으로 연결하면, 앞 단의 출력이 0→1로 바뀔 때마다 다음 단이 토글된다. 이렇게 n개의 플립플롭을 연결하면 n비트 이진 카운터가 된다.

3비트 카운터는 000 → 001 → 010 → 011 → 100 → 101 → 110 → 111 → 000 순서로 반복된다. 2³ = 8개의 상태를 순환한다.

## 프로그램 카운터

Chapter 17에서 만든 자동화 가산기에서 16비트 카운터는 RAM 배열의 주소를 순서대로 생성하는 역할을 한다. 이것이 바로 프로세서에서 말하는 프로그램 카운터(Program Counter, PC)다. 다음에 실행할 명령어의 주소를 가리킨다.

클럭이 한 번 뛸 때마다 카운터가 증가하면서 다음 메모리 주소를 가리킨다. Jump 명령어가 실행되면 카운터의 Preset/Clear 입력을 이용해 지정된 주소로 강제로 바꿔줄 수 있다.
