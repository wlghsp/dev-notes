# 32bit / 64bit

CPU가 한 번에 처리할 수 있는 주소 크기를 말한다.

## 주소 크기가 왜 중요한가

주소 크기가 곧 표현할 수 있는 메모리 범위다.

- 32비트 → 2^32 = 4GB까지만 주소를 가리킬 수 있다
- 64비트 → 2^64 = 약 1800경 바이트. 사실상 한계 없음

32비트 OS에서 RAM을 4GB 이상 꽂아도 쓸 수 없었던 이유가 이거다. 주소 자체가 4GB 이상을 가리킬 수 없기 때문이다.

## 페이지 테이블과의 연결

주소 크기가 커지면 페이지 테이블도 커진다.

32비트 기준 (페이지 4KB = 오프셋 12비트):
- 페이지 번호: 32 - 12 = 20비트
- 페이지 테이블 항목 수: 2^20 = 약 100만 개

64비트 기준 (페이지 4KB = 오프셋 12비트):
- 페이지 번호: 64 - 12 = 52비트
- 페이지 테이블 항목 수: 2^52 = 어마어마하게 많음

64비트에서 페이지 테이블을 하나로 만들면 테이블 자체가 메모리를 다 잡아먹는다. 그래서 다단계 페이지 테이블이 필요한 거다. 참고: page-table.md

## 역사적 맥락

2000년대 초반까지는 RAM이 4GB를 넘기 어려웠다. 32비트로 충분했다. RAM 가격이 떨어지고 4GB를 넘기 시작하면서 32비트 OS로는 감당이 안 됐고, 64비트로 전환이 시작됐다.

지금 맥북, 윈도우 전부 64비트 OS다. 32비트는 구형 임베디드나 레거시 환경에서만 남아있다.
