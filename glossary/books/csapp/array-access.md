# array-access (배열의 기계어 표현)

C에서 배열은 연속된 메모리 블록이다. 기계어 수준에서 배열 접근은 시작 주소에 인덱스×원소 크기를 더한 주소를 계산하는 것이다.

## 기본 원리

타입 T의 배열 A가 시작 주소 xa에 있을 때, A[i]의 주소는:

`xa + i × sizeof(T)`

```c
int a[5];        // int 4바이트
// a[3]의 주소 = &a[0] + 3*4 = &a[0] + 12
```

어셈블리에서 스케일드 인덱스 주소 지정으로 표현된다:
```asm
movl (%rax,%rdx,4), %ecx   # a[i] 읽기 (rax=&a[0], rdx=i)
```

## 다차원 배열 — row-major order

C의 다차원 배열은 row-major로 저장된다. 행 전체가 연속으로 저장된다.

```c
int a[3][4];  // 3행 4열
// a[1][2]의 주소 = &a[0][0] + (1*4 + 2) * sizeof(int)
//               = &a[0][0] + 6*4 = &a[0][0] + 24
```

`a[i][j]`의 주소 = 시작 주소 + (i×열 수 + j) × 원소 크기

## 포인터와 배열

C에서 배열 이름은 첫 번째 원소의 포인터로 암묵적 변환된다. `a[i]`와 `*(a+i)`는 동일하다.

어셈블리 수준에서도 둘의 차이가 없다. 포인터 연산이 주소 계산으로 그대로 변환된다.

## 경계 검사 없음

C는 배열 인덱스 범위를 검사하지 않는다. `a[10]`이 배열 크기를 벗어나도 컴파일러는 그냥 주소를 계산하고 접근한다. 이것이 버퍼 오버플로우의 근본 원인이다.
