# 주소 버스 (Address Bus)

CPU가 메모리의 특정 위치를 가리키기 위해 사용하는 신호선 묶음. 주소 버스의 비트 수가 접근 가능한 메모리 위치의 개수를 결정한다.

## 주소 비트와 접근 가능한 위치 수

RAM에서 저장할 수 있는 값의 개수는 주소 입력 비트 수에 의해 결정된다.

- 주소 1비트 → 2개
- 주소 2비트 → 4개
- 주소 3비트 → 8개
- 주소 n비트 → 2ⁿ개

주소 버스 비트를 하나 추가할 때마다 접근 가능한 메모리 용량이 두 배가 된다.

## 주소 버스와 메모리 용량

주소 비트 10개면 2¹⁰ = 1024개의 위치를 가리킬 수 있다. 각 위치에 1바이트(8비트)를 저장하면 총 1024바이트 = 1킬로바이트(1KB)다.

주소 비트 20개면 2²⁰ = 1,048,576개의 위치 = 1메가바이트(1MB). 주소 비트 30개면 약 1기가바이트(1GB)다.

## 킬로/메가/기가의 의미

메모리 단위에서 kilo는 정확히 1000이 아니라 1024(= 2¹⁰)다. 10진수 기반의 SI 접두사를 2진수 기반의 메모리에 빌려 쓰기 때문이다. 2¹⁰ ≈ 10³ 이라는 근사값이 그 근거다.

- 1KB = 1024바이트 = 2¹⁰바이트
- 1MB = 1,048,576바이트 = 2²⁰바이트
- 1GB = 1,073,741,824바이트 = 2³⁰바이트
- 1TB = 2⁴⁰바이트
- 1PB = 2⁵⁰바이트

각 단계는 이전 단계의 정확히 1024배다.
