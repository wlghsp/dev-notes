# binary-combinations (이진 조합)

두 가지 선택지가 n번 반복될 때 만들어지는 조합의 수는 2ⁿ이다.

## 공식

길이 1: 2가지 = 2¹
길이 2: 4가지 = 2²
길이 3: 8가지 = 2³
길이 n: 2ⁿ가지

각 단계마다 이전 단계의 모든 코드 뒤에 점을 붙인 것과 대시를 붙인 것이 추가된다. 항상 2배씩 늘어난다.

## 컴퓨터에서의 의미

- 1비트 → 2가지
- 8비트(1바이트) → 256가지
- 16비트 → 65,536가지
- 32비트 → 약 42억 가지

비트 하나가 늘 때마다 표현 범위가 정확히 두 배가 된다.

## 역방향 계산

N가지를 표현하려면 몇 비트가 필요한지도 이 공식으로 구한다.

26개 알파벳 → 2⁵ = 32 > 26 → 최소 5비트
64개 → 2⁶ = 64 → 6비트
256개 → 2⁸ = 256 → 8비트(1바이트)
