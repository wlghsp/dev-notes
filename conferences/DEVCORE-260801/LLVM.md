# LLVM

LLVM은 컴파일러를 만들기 위한 인프라다. 컴파일러 하나를 통째로 만드는 대신, 프론트엔드(언어별 파서)와 백엔드(CPU 아키텍처별 코드 생성)를 분리하고 그 사이를 LLVM IR이라는 공통 중간 표현으로 잇는다.

이 구조 덕분에 새 언어를 만드는 사람은 자기 언어를 LLVM IR로 변환하는 프론트엔드만 작성하면 되고, x86이나 ARM 같은 각 아키텍처용 기계어 생성은 LLVM 백엔드가 대신 해준다. 반대로 새 하드웨어를 지원하려는 사람은 백엔드 하나만 추가하면 LLVM IR을 사용하는 모든 언어가 그 하드웨어를 지원받는다. Clang(C/C++), Swift, Rust가 모두 이 구조 위에서 동작한다.

LLVM IR은 정적 단일 할당(SSA) 형태를 취하는데, 각 변수가 딱 한 번만 값을 대입받도록 강제해서 컴파일러가 최적화(불필요한 계산 제거, 값 전파 등)를 더 쉽게 판단할 수 있게 만든다.
